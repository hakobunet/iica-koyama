# Хичээл 08 Дасгал｜Хариуны жишээ

> 🇯🇵 Эх хувь (япон хэлээр): [20260723_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260723/20260723_解答.md>) <!-- original-ja-link -->

`students` хүснэгтийн анхны өгөгдөл (Хичээл 07-ын материалыг үзнэ үү)-д тулгуурласан хариуны жишээ.
Тусгайлан заагаагүй бол асуулт бүрийг «анхны өгөгдөл дээр хийх үйлдэл» гэж тус тусад нь авч үзнэ.

```
Анхны өгөгдөл (10 бичлэг)
 id │ name     │ age │ class │ score
────┼──────────┼─────┼───────┼──────
  1 │ 田中太郎 │ 18  │ A     │ 85
  2 │ 鈴木花子 │ 19  │ A     │ 72
  3 │ 山田次郎 │ 18  │ B     │ 91
  4 │ 佐藤三郎 │ 20  │ B     │ 58
  5 │ 伊藤美咲 │ 18  │ A     │ 78
  6 │ 渡辺一郎 │ 19  │ C     │ 95
  7 │ 加藤幸子 │ 18  │ C     │ 45
  8 │ 吉田健太 │ 20  │ B     │ 88
  9 │ 山本麻衣 │ 19  │ A     │ 67
 10 │ 中村龍一 │ 18  │ C     │ 73
```

---

## Асуулт 1 (INSERT)

### Хариу

```sql
-- ① 新入生F-ийн нэг бичлэг нэмэх
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② 新入生G болон 新入生H-ийг нэг INSERT командаар нэмэх
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**Үр дүн (лавлагаа):**
- ①: `id=11` болж «新入生F» нэмэгдэнэ (`id` нь AUTO_INCREMENT тул заах шаардлагагүй)
- ②: `id=12` «新入生G», `id=13` «新入生H» зэрэг нэмэгдэнэ

---

## Асуулт 2 (UPDATE)

### Хариу

```sql
-- ① id=3 бүхий сурагчийн class-ийг 'S' болгож шинэчлэх
UPDATE students SET class = 'S' WHERE id = 3;

-- ② class нь 'B' бүхий бүх сурагчийн score-д 10 оноо нэмэх
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**Үр дүн (лавлагаа):**
- ①: 山田次郎 (id=3)-ийн `class` нь `B` → `S` болж өөрчлөгдөнө
- ②: class='B' байгаа 3 сурагч хамрагдана
  - 山田次郎: 91 → 101
  - 佐藤三郎: 58 → 68
  - 吉田健太: 88 → 98

③-ын тайлбар:
> `WHERE`-ийг бичихээ мартаад `UPDATE students SET score = 0;`-ийг ажиллуулбал `students` хүснэгтийн **бүх 10 бичлэг** хамрагдаж, бүх сурагчийн `score` ямар байснаас үл хамааран 0 оноо болно. `UPDATE`/`DELETE`-ийг ажиллуулахаасаа өмнө `WHERE`-ийг заавал шалгах хэрэгтэй.

---

## Асуулт 3 (DELETE)

### Хариу

```sql
-- ① id=8 бүхий сурагчийг устгах
DELETE FROM students WHERE id = 8;

-- ② score нь 40 онооноос бага бүх сурагчийг устгах
DELETE FROM students WHERE score < 40;

-- ③ ②-ыг ажиллуулахаас өмнө хамрах мөрүүдийг SELECT-ээр шалгах
SELECT * FROM students WHERE score < 40;
```

**Үр дүн (лавлагаа):**
- ①: 吉田健太 (id=8) устгагдана
- ②: Анхны өгөгдлийн хамгийн бага оноо 45 (加藤幸子) тул `score < 40` нөхцөлд тохирох сурагч **0** байна. Өөрөөр хэлбэл энэ `DELETE` юу ч устгахгүй («0 бичлэг хамрагдсан» нь ч зөв гүйцэтгэлийн үр дүн)
- ③: ②-ын `DELETE`-ээс өмнө заавал ажиллуулж, устгагдах мөрүүд нь устгахыг зорьсон мөрүүд мөн эсэхийг нүдээр шалгасны дараа `DELETE`-ийг ажиллуулна (материалын 4-р бүлэг «UPDATE/DELETE-ийг аюулгүй хийх арга»-г үзнэ үү)
