`students` хүснэгтийн өгөгдөл（Хичээл 07-ын материалыг харна уу）дээр үндэслэсэн хариултын жишээ.

---

## Бодлого 1（SELECT-ийн үндэс）

### Хариу

```sql
-- ① Зөвхөн name ба class-ийг авна
SELECT name, class FROM students;

-- ② name AS 氏名, score AS 点数 гэж авна
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ Бүх багана・бүх мөрийг авна
SELECT * FROM students;
```

---

## Бодлого 2（WHERE）

### Хариу

```sql
-- ① class нь 'B' байх сурагчид
SELECT * FROM students WHERE class = 'B';

-- ② age нь 18 ба түүнээс дээш, мөн score нь 80 ба түүнээс дээш
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class нь 'A' эсвэл 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name-д「郎」орсон
SELECT * FROM students WHERE name LIKE '%郎%';
```

**Үр дүн（лавлагаа）:**
- ①: 山田次郎(91)、佐藤三郎(58)、吉田健太(88)
- ②: 田中太郎(85)、山田次郎(91)、渡辺一郎(95)、吉田健太(88)
- ③: 田中太郎・鈴木花子・伊藤美咲・山本麻衣（A）、渡辺一郎・加藤幸子・中村龍一（C）
- ④: 田中太郎・山田次郎・佐藤三郎・渡辺一郎（4 хүн）

---

## Бодлого 3（ORDER BY / LIMIT）

### Хариу

```sql
-- ① Бүх сурагчийг score-оор буурах дарааллаар
SELECT * FROM students ORDER BY score DESC;

-- ② Зөвхөн эхний 3 хүн
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class-аар өсөх, ижил class дотор score-оор буурах дарааллаар
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**Үр дүн（лавлагаа）:**

②
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

③
```

[B] 山田次郎91, 吉田健太88, 佐藤三郎58
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## Бодлого 4（нэгтгэх функц）

### Хариу

```sql
-- ① Хүний тоо
SELECT COUNT(*) FROM students;

-- ② Нийлбэр・дундаж・хамгийн их・хамгийн багыг нэг дор авна
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**Үр дүн（лавлагаа）:**
- ①: 10 хүн
- ②: 合計点 752 ／ 平均点 75.2 ／ 最高点 95 ／ 最低点 45

---

## Бодлого 5（ахисан түвшин）

### Хариу

```sql
-- ① 60 ба түүнээс дээш оноотой сурагчдыг хамруулж, class тус бүрийн дундаж оноо, сурагчдын тоог дундаж оноогоор нь ихээс бага руу эрэмбэлнэ
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② class = 'A' дотроос хамгийн өндөр оноотой ганц сурагч
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**Үр дүн（лавлагаа）:**

①（60-аас доош оноотой 佐藤三郎・加藤幸子 хасагдана）
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②
```
田中太郎 85点
```
