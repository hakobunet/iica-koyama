## Part 3｜Форм ба POST

### Бодлого 3-1: Лавлагааны форм хийх

`contact.php` нэртэй нэг файл үүсгээрэй.

**Шаардлага:**
- Оруулах талбарууд: нэр・имэйл хаяг・мессеж
- Илгээсний дараа「〇〇さんからのお問い合わせを受け付けました」（〇〇-аас ирсэн лавлагааг хүлээн авлаа）гэж харуулна
- XSS-ээс хамгаалахын тулд `htmlspecialchars()`-ийг заавал ашиглана

```php
<?php
// ▼ contact.php-д бичээрэй

$name    = "";
$email   = "";
$message = "";
$sent    = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // ① Өгөгдлийг авна（?? ""-ээр утга байхгүй эсвэл null бол хоосон мөр ашиглана）

    // ② htmlspecialchars-аар дамжуулна

    $sent = true;
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>問い合わせ</title></head>
<body>
<?php if ($sent): ?>
  <!-- Амжилттай илгээсэн тухай мессеж -->
<?php else: ?>
  <!-- Форм -->
<?php endif; ?>
</body>
</html>
```

### Бодлого 3-2: Валидацитай форм хийх

`register.php`-ийг үүсгэж, дараах валидацийг хэрэгжүүлээрэй.

**Валидацийн нөхцөл:**
- Нэр: заавал・50 тэмдэгтээс хэтрэхгүй
- Нас: заавал・0〜120 хүртэлх бүхэл тоо
- Алдаа гарвал улаанаар жагсааж харуулах ба оруулсан утгыг хадгалж үлдээнэ

    $age  = trim($_POST["age"]  ?? "");

    // ② Насны валидаци

<head><meta charset="UTF-8"><title>登録</title></head>
