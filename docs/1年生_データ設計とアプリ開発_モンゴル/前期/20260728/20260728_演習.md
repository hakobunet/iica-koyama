## Өнөөдрийн дасгалын агуулга

Хичээл 09-д үүсгэсэн `school_db`-ийн users / products / orders хүснэгтүүдийг ашиглан бодлогуудыг бодоорой.

---

## Дасгал 1: Үндсэн SELECT

```sql
-- ① orders хүснэгтийн бүх өгөгдлийг харуулна уу
--    Хүлээгдэх үр дүн: 5 бичлэг (Хичээл 09-д бүртгэсэн бүх захиалгын өгөгдөл)

-- ② products хүснэгтээс price нь 5000 иен ба түүнээс дээш барааг гаргана уу
--    Хүлээгдэх үр дүн: ノートPC(98000), キーボード(8500) гэсэн 2 бичлэг (マウス хамаарахгүй)

-- ③ users хүснэгтийн хэрэглэгчдийг id-ийн буурах дарааллаар харуулна уу
--    Хүлээгдэх үр дүн: 山田次郎(id=3) → 鈴木花子(id=2) → 田中太郎(id=1) гэсэн дараалал

-- ④ products хүснэгтээс хамгийн үнэтэй болон хамгийн хямд барааны үнийг харуулна уу
--    Хүлээгдэх үр дүн: хамгийн өндөр үнэ 98000 / хамгийн бага үнэ 3200
```

## Дасгал 2: INSERT / UPDATE / DELETE

```sql
-- ① Дараах хэрэглэгчийг нэмнэ үү
--    Нэр: 中村健二, И-мэйл: nakamura@example.com
--    Хүлээгдэх үр дүн: 中村健二 id=4-тэй хэрэглэгчээр нэмэгдэнэ

-- ② products хүснэгтэд «USBハブ» (үнэ: 2800 иен)-ийг нэмнэ үү
--    Хүлээгдэх үр дүн: USBハブ(2800 иен) id=4-тэй бараагаар нэмэгдэнэ

-- ③ 田中太郎 USBハブ-ыг 3 ширхэг захиалсан бичлэгийг orders-д нэмнэ үү
--    Зөвлөгөө: эхлээд 田中太郎-ийн id болон USBハブ-ын id-г SELECT-ээр шалгана
--    (2 алхмаар хийсэн ч болно. 1 командаар бичих хүсэлтэй хүн материалын 8-р бүлэг «Subquery»-г үзнэ үү)
--    Хүлээгдэх үр дүн: (user_id=1, product_id=4, quantity=3) нь id=6-тай захиалгаар нэмэгдэнэ

-- ④ ノートPC-ийн үнийг 95000 иен болгож шинэчилнэ үү
--    Зөвлөгөө: SELECT-ээр шалгасны дараа UPDATE хийнэ
--    Хүлээгдэх үр дүн: ノートPC-ийн price нь 98000 → 95000 болж өөрчлөгдөнө

-- ⑤ Нэмсэн 中村健二-ийн захиалгын өгөгдөл байвал устгаж, дараа нь 中村健二-г өөрийг нь устгана уу
--    Зөвлөгөө: гадаад түлхүүрийн хязгаарлалт байгаа тул orders-оос эхэлж устгах шаардлагатай
--    Зөвлөгөө: 中村健二-ийн id-г мэдэхгүй байсан ч материалын 8-р бүлэг «Subquery»-ийн бичих аргыг ашиглавал
--    (SELECT id FROM users WHERE name = '中村健二')-ээр 1 команд болгон нэгтгэж болно
--    Хүлээгдэх үр дүн: 中村健二-ийн захиалга 0 тул эхний DELETE 0 бичлэгт нөлөөлж,
--    2 дахь DELETE-ээр 中村健二(id=4) устгагдана
```

## Дасгал 3: JOIN ба нэгтгэн тооцоолол

(Дасгал 2-ын өөрчлөлтийг тусгахаас өмнөх, Хичээл 09-ийн анхны өгөгдлийг үндэслэн бодоорой)

```sql
-- ① Бүх захиалгыг «хэрэглэгчийн нэр, барааны нэр, тоо ширхэг, нийт дүн» хэлбэрээр харуулна уу
--    Хүлээгдэх үр дүн: 5 мөр (田中太郎×2, 鈴木花子×2, 山田次郎×1)

-- ② 田中太郎-ийн захиалгын жагсаалтыг барааны нэр, үнийн дүнтэй нь харуулна уу
--    Хүлээгдэх үр дүн: ノートPC(1 ширхэг, 98000 иен), マウス(2 ширхэг, 6400 иен) гэсэн 2 мөр

-- ③ Бараа бүрийн борлуулалтын нийт дүнг «барааны нэр, борлуулсан тоо, борлуулалтын нийт дүн» хэлбэрээр
--    борлуулалтын нийт дүнгийн буурах дарааллаар харуулна уу
--    Хүлээгдэх үр дүн: ノートPC(3 ширхэг, 294000 иен) → キーボード(1 ширхэг, 8500 иен) → マウス(2 ширхэг, 6400 иен)

-- ④ Хараахан захиалга өгч байгаагүй хэрэглэгчийг хайна уу
--    Зөвлөгөө: LEFT JOIN + WHERE orders.id IS NULL-ийг ашиглана
--    (Энэ аргын тайлбарыг материалын 5-1 «хараахан захиалга өгөөгүй хэрэглэгчдийг л хайх»-аас үзнэ үү)
--    Хүлээгдэх үр дүн: 0 бичлэг (анхны өгөгдөлд бүгд дор хаяж 1 удаа захиалга өгсөн тул)
```

## Дасгал 4: Ахисан түвшний бодлого (сонголтоор, цаг үлдвэл оролдоорой)

Дасгал 1–3-ыг хийж чадвал өнөөдрийн зорилго биелнэ. Дасгал 4-т `HAVING` зэрэг шинэ агуулга орсон тул
бүгдийг заавал бодох шаардлагагүй. (Үргэлжлүүлэн Хичээл 09-ийн анхны өгөгдлийг үндэслэн бодоорой)

```sql
-- ① Худалдан авалтын дундаж дүн нь хамгийн өндөр хэрэглэгчийг олно уу
--    Хүлээгдэх үр дүн: 山田次郎 (дундаж 98000 иен. 田中太郎 52200 иен, 鈴木花子 53250 иен)

-- ② Хэрэглэгч бүрийн «хамгийн сүүлийн захиалгын огноо, цаг»-ийг харуулна уу
--    Зөвлөгөө: GROUP BY + MAX(ordered_at)
--    Хүлээгдэх үр дүн: анхны өгөгдлийг 1 INSERT-ээр нэг дор бүртгэсэн тул 3 хүнийх ижил огноо, цаг байна

-- ③ Захиалгын нийт дүн 100000 иен ба түүнээс дээш хэрэглэгчийн нэр болон и-мэйлийг харуулна уу
--    Зөвлөгөө: GROUP BY + HAVING SUM(...) >= 100000
--    (WHERE ба HAVING-ийн ялгааг материалын 7-р бүлэг «HAVING»-аас үзнэ үү)
--    Хүлээгдэх үр дүн: 田中太郎(104400 иен), 鈴木花子(106500 иен) гэсэн 2 хүн (山田次郎 98000 иен тул хамаарахгүй)
```
