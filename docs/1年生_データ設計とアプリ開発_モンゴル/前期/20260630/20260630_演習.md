# Хичээл 02 Дасгал｜PHP-ийн үндсэн синтаксийг ашиглан код ажиллуулж үзье

> 🇯🇵 Эх хувь (япон хэлээр): [20260630_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260630/20260630_演習.md>) <!-- original-ja-link -->

`src/index.php` файл үүсгээд, бодлого бүрийн кодыг бичиж, `php -S localhost:8000` командыг ашиглан ажиллаж байгаа эсэхийг шалгаарай.

---

## Бодлого 1: Өөрийгөө танилцуулах

`$name`・`$age`・`$hobby` хувьсагчдыг тодорхойлж, доорх жишээний дагуу үр дүнг харуулах PHP файл бичээрэй.

**Хүлээгдэж буй гаралтын жишээ（браузерт харагдана）:**
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

Нөхцөл:
- Хувьсагч заавал `$`-ээр эхэлнэ
- Хувьсагчийг тэмдэгт мөр дотор оруулж, `"..."` хэлбэрээр гаргана

```php
<?php
// Энд бичээрэй


?>
```

---

## Бодлого 2: Массивыг HTML жагсаалтаар харуулах

`$fruits = ["りんご", "みかん", "ぶどう", "バナナ"]`-ийг `foreach`-ээр давтаж, `<ul>` / `<li>` таг ашиглан HTML хэлбэрээр харуулаарай.

**Хүлээгдэж буй гаралт（браузерт харагдана）:**
```
• りんご
• みかん
• ぶどう
• バナナ
```

Нөхцөл:
- `foreach` ашиглах
- HTML-ийн `<ul>` ба `<li>` тагийг echo-гоор гаргах

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// Энд бичээрэй


?>
```

---

## Бодлого 3: 1-ээс 10 хүртэлх тооны нийлбэрийг бодох

`for` давталт ашиглан 1-ээс 10 хүртэлх бүх бүхэл тооны нийлбэрийг хэвлээрэй.

**Хүлээгдэж буй гаралт:**
```
合計: 55
```

Нөхцөл:
- `for` давталт ашиглах
- Нийлбэрийг хадгалах `$total` хувьсагч ашиглах

```php
<?php
$total = 0;

// Энд бичээрэй


echo "合計: " . $total;
?>
```

---

## Бодлого 4（ахисан түвшин）: Үржвэрийн хүснэгт хийх

`for` давталтыг давхар ашиглаж, 2-оос 5 хүртэлх тооны үржвэрийн хүснэгтийг харуулаарай.

**Хүлээгдэж буй гаралт（хэсэг）:**
```
2×1=2  2×2=4  2×3=6 ...
3×1=3  3×2=6  3×3=9 ...
```

```php
<?php
// Энд бичээрэй


?>
```
