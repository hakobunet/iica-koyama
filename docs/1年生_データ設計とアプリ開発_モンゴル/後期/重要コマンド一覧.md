> Командуудыг **VS Code-ийн терминал** дээр бичнэ.
> Docker Desktop-ийг асаасны дараа ашиглаарай.

---

## Асаах, зогсоох

### Асаах (эхлээд mysql, дараа нь laravel)

```powershell
docker compose up -d
```

### Зогсоох (эхлээд laravel, дараа нь mysql)

```powershell
docker compose down
```

Асаасны дараа хөтөч дээр нээнэ.

| URL | Харагдах зүйл |
|-----|------------|
| http://localhost:8000 | Laravel (хийж байгаа апп) |
| http://localhost:8080 | phpMyAdmin (өгөгдлийн сан) |

---

## Файл үүсгэх

Эдгээр командыг laravel хавтсанд ажиллуулна.

### Миграцийн файл үүсгэх

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### Модель үүсгэх

```powershell
docker compose exec laravel php artisan make:model Todo
```

### Контроллер үүсгэх

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## Өгөгдлийн сантай ажиллах

Эдгээр командыг laravel хавтсанд ажиллуулна.

### Хүснэгт үүсгэх

```powershell
docker compose exec laravel php artisan migrate
```
