# 🔓 ホワイトハッカー ミッションカード

**ホワイトハッカー＝「悪いハッカーから人を守るために、あえて攻撃の技術を学ぶ人」。**
今日はあなたが「攻撃する側」を体験し、**どうすれば守れるか**を見つけます。

触るのは `index.html` の **★実験ゾーン★** にある **2つの数字だけ**。

```js
const LENGTH = 4;    // パスワードの長さ
const KINDS  = 10;   // 使える文字の種類
```

書き換えたら **F5（画面更新）** で結果が変わります。

---

## MISSION 1：長さの威力を暴け

`KINDS` は `10`（数字だけ）のまま、`LENGTH` だけ変えて表を埋めてください。

| LENGTH | 解読時間（画面の数字を書く） |
|---|---|
| 4 | |
| 6 | |
| 8 | |
| 10 | |

> 💡 **1文字増えるだけで、時間は何倍になった？**

---

## MISSION 2：文字の種類の威力を暴け

今度は `LENGTH` を `8` に固定して、`KINDS` を変えてください。

| KINDS | どんな文字 | 解読時間 |
|---|---|---|
| 10 | 数字だけ | |
| 26 | 小文字だけ | |
| 62 | 英大文字＋小文字＋数字 | |
| 95 | 記号も全部入り | |

> 💡 **「長さ」と「種類」、どっちを増やすほうが効く？**

---

## MISSION 3：最強のパスワードを設計せよ

「破られるまで **100年以上**」になる組み合わせを、いくつ見つけられる？
（画面が **緑色** になったら合格ライン）

- 例：`LENGTH = 12` / `KINDS = 62` は？
- できるだけ **短くて、覚えやすくて、それでも安全**な設定を探そう

---

## FINAL：自分を守れ（型だけ診断）

画面いちばん下の **CHECK** で、あなたが**ふだん使いがちなパスワードの「形」**を入れてみよう。

> ⚠️ **本物は絶対に入れないこと！**
> `birthday1` みたいな「よくある形」を、`aaaaaaaa9` のように置き換えて入れる。
> このツールは長さと文字の種類しか見ていないので、本物を入れる必要はありません。

**あなたのパスワード、何秒で破られましたか？**

---

## 今日の学び

- パスワードは **「複雑さ」より、まず「長さ」** が効く
- **記号を1種類混ぜる**だけで、解読時間が桁違いに伸びる
- そして──**攻撃の仕組みを知っている人だけが、正しく守れる。**
  これがホワイトハッカー（セキュリティエンジニア）の仕事です。
