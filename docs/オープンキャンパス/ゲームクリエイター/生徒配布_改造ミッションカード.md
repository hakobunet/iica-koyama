# 🎮 ゲームクリエイター 改造ミッション

**あなたへの依頼：この「クソゲー」を、遊びたくなるゲームに作り変えてください。**

触るのは `index.html` の **★改造ゾーン★** だけ。それより下は触らなくてOK。

---

## MISSION 1：ゲームバランスを整えろ（レベルデザイン）

いまの設定は、**絶対にクリアできない**バランスになっています。数字を変えて、「ちょうどいい難しさ」を探してください。

| 変数 | いまの値 | 何が変わる？ |
|---|---|---|
| `SPEED` | `12` | 大きいほど速い |
| `GRAVITY` | `1.5` | 大きいほど体が重い |
| `JUMP_POWER` | `6` | 大きいほど高く跳ぶ |
| `OBSTACLE_INTERVAL` | `60` | 小さいほど障害物が連発する |

> 💡 **書き換えたら、ゲームのタブを更新（F5）するだけで反映されます。**
> 「跳べない」なら？「速すぎ」なら？──どこをいじる？

**ゴール：友達が「もう1回！」と言うバランスを見つける。**
（どうしても決まらない人向けの参考値 → `SPEED 7` / `GRAVITY 0.9` / `JUMP_POWER 18` / `OBSTACLE_INTERVAL 75`）

## MISSION 2：自分だけのゲームにしろ（アートディレクション）

絵文字と色を、好きなものに変えてください。

```js
const GAME_TITLE   = "阿蘇あか牛ラン";  // タイトル
const PLAYER       = "🐄";              // 主人公
const OBSTACLE     = "🪨";              // 障害物
const BONUS        = "🌟";              // ラッキーアイテム
const SKY_COLOR    = "#87CEEB";         // 空の色
const GROUND_COLOR = "#7CB342";         // 地面の色
```

- 絵文字は **Windowsキー + .（ピリオド）** で出せます
- 色は `#87CEEB` のような6ケタの英数字（カラーコード）。「カラーコード ジェネレーター」で検索してもOK

## MISSION 3：必殺技を実装しろ（機能追加）

下のコードを **コピーして、指定の場所に貼りつける**。好きなだけ組み合わせてOK。

### ① 二段ジャンプ
貼る場所 → `// ★HOOK-JUMP★` と書いてある行の**すぐ下**

```js
  else if (player.jumpCount === 1) {
    player.vy = -JUMP_POWER;
    player.jumpCount = 2;
  }
```

### ② だんだん速くなる（＝ちゃんと盛り上がるゲームになる）
貼る場所 → `// ★HOOK-FRAME★` と書いてある行の**すぐ下**

```js
  if (frame % 300 === 0) {
    speed = speed + 1;
  }
```

### ③ ラッキーアイテム出現（取ると +300点）
貼る場所 → `// ★HOOK-FRAME★` と書いてある行の**すぐ下**

```js
  if (frame % 400 === 0) {
    spawnBonus();
  }
```

> 💡 `300` や `400` の数字も自由に変えてOK。小さくすると…？
