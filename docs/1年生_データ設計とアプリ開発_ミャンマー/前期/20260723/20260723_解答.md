# သင်ချိန် 08 လေ့ကျင့်ခန်း｜အဖြေနမူနာ

> 🇯🇵 မူရင်း (ဂျပန်ဘာသာဖြင့်): [20260723_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260723/20260723_解答.md>) <!-- original-ja-link -->

`students` Table ရဲ့ ကနဦးဒေတာ (သင်ချိန် 07 သင်ခန်းစာကို ကြည့်ပါ) ကို အခြေခံထားတဲ့ အဖြေနမူနာပါ။
သီးသန့် ဖော်ပြထားခြင်း မရှိရင် မေးခွန်းတစ်ခုချင်းကို 「ကနဦးဒေတာကနေ စလုပ်တဲ့ လုပ်ဆောင်ချက်」အဖြစ် သီးခြားစီ စဉ်းစားပါ။

```
ကနဦးဒေတာ (10 ခု)
 id │ name     │ age │ class │ score
────┼──────────┼─────┼───────┼──────
  1 │ 田中太郎 │ 18  │ A     │ 85
  2 │ 鈴木花子 │ 19  │ A     │ 72
  3 │ 山田次郎 │ 18  │ B     │ 91
  4 │ 佐藤三郎 │ 20  │ B     │ 58
  5 │ 伊藤美咲 │ 18  │ A     │ 78
  6 │ 渡辺一郎 │ 19  │ C     │ 95
  7 │ 加藤幸子 │ 18  │ C     │ 45
  8 │ 吉田健太 │ 20  │ B     │ 88
  9 │ 山本麻衣 │ 19  │ A     │ 67
 10 │ 中村龍一 │ 18  │ C     │ 73
```

---

## မေးခွန်း 1 (INSERT)

### အဖြေ

```sql
-- ① ကျောင်းသားသစ် 新入生F ၏ မှတ်တမ်းတစ်ခုကို ထည့်ခြင်း
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② ကျောင်းသားသစ် 新入生G နှင့် 新入生H ကို INSERT statement တစ်ခုတည်းနဲ့ ထည့်ခြင်း
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**ရလဒ် (ကိုးကားရန်):**
- ①: `id=11` အဖြစ် 「新入生F」(ကျောင်းသားသစ် F) ကို ထည့်ပေးပါတယ် (`id` က AUTO_INCREMENT ဖြစ်လို့ သတ်မှတ်ပေးစရာ မလိုပါ)
- ②: `id=12`「新入生G」(ကျောင်းသားသစ် G) နဲ့ `id=13`「新入生H」(ကျောင်းသားသစ် H) ကို တစ်ပြိုင်နက် ထည့်ပေးပါတယ်

---

## မေးခွန်း 2 (UPDATE)

### အဖြေ

```sql
-- ① id=3 ဖြစ်တဲ့ ကျောင်းသားရဲ့ class ကို 'S' လို့ ပြင်ခြင်း
UPDATE students SET class = 'S' WHERE id = 3;

-- ② class က 'B' ဖြစ်တဲ့ ကျောင်းသားအားလုံးရဲ့ score ကို +10
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**ရလဒ် (ကိုးကားရန်):**
- ①: 山田次郎 (id=3) ရဲ့ `class` က `B` → `S` ပြောင်းသွားပါတယ်
- ②: class='B' ဖြစ်တဲ့ ကျောင်းသား ၃ ယောက်အပေါ် သက်ရောက်ပါတယ်
  - 山田次郎: 91 → 101
  - 佐藤三郎: 58 → 68
  - 吉田健太: 88 → 98

③ ရဲ့ ရှင်းလင်းချက်:
> `WHERE` ထည့်ဖို့ မေ့ပြီး `UPDATE students SET score = 0;` ကို Run လိုက်ရင် `students` Table ရဲ့ **Row ၁၀ ခုလုံး** သက်ရောက်ပြီး လူတိုင်းရဲ့ `score` က ခြွင်းချက်မရှိ ၀ မှတ် ဖြစ်သွားပါလိမ့်မယ်။ `UPDATE`/`DELETE` ကို Run မလုပ်ခင် `WHERE` ကို အမြဲ စစ်ဆေးဖို့ လိုပါတယ်။

---

## မေးခွန်း 3 (DELETE)

### အဖြေ

```sql
-- ① id=8 ဖြစ်တဲ့ ကျောင်းသားကို ဖျက်ခြင်း
DELETE FROM students WHERE id = 8;

-- ② score က ၄၀ မှတ်အောက် ဖြစ်တဲ့ ကျောင်းသားအားလုံးကို ဖျက်ခြင်း
DELETE FROM students WHERE score < 40;

-- ③ ② ကို Run မလုပ်ခင် သက်ရောက်မယ့် Row တွေကို SELECT နဲ့ စစ်ဆေးခြင်း
SELECT * FROM students WHERE score < 40;
```

**ရလဒ် (ကိုးကားရန်):**
- ①: 吉田健太 (id=8) ကို ဖျက်လိုက်ပါတယ်
- ②: ကနဦးဒေတာရဲ့ အနိမ့်ဆုံးအမှတ်က ၄၅ မှတ် (加藤幸子) ဖြစ်လို့ `score < 40` နဲ့ ကိုက်ညီတဲ့ ကျောင်းသား **၀ ယောက်** ပါ။ ဆိုလိုတာက ဒီ `DELETE` က ဘာမှ မဖျက်ပါဘူး (「သက်ရောက်တဲ့ Row ၀ ခု」ဆိုတာလည်း မှန်ကန်တဲ့ Run ရလဒ်ပါပဲ)
- ③: ② ရဲ့ `DELETE` မတိုင်ခင် ဒီ `SELECT` ကို အမြဲ အရင် Run လုပ်ပြီး ဖျက်မယ့် Row တွေက ရည်ရွယ်ထားတဲ့အတိုင်း ဟုတ်မဟုတ် မျက်စိနဲ့ စစ်ဆေးပါ။ ပြီးမှ `DELETE` ကို Run လုပ်ပါ (သင်ခန်းစာ အခန်း 4 「ဘေးကင်းတဲ့ UPDATE/DELETE လုပ်နည်း」ကို ကြည့်ပါ)
