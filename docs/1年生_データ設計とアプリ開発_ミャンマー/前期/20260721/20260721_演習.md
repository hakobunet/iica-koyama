## ပုစ္ဆာ 1（SELECT အခြေခံ）：လိုအပ်တဲ့ column တွေကိုပဲ ထုတ်ယူခြင်း

1. `name` နဲ့ `class` ကိုပဲ ယူပါ
2. `name` ကို「氏名」（အမည်အပြည့်အစုံ）၊ `score` ကို「点数」（အမှတ်）ဆိုတဲ့ alias（AS）နဲ့ ယူပါ
3. Table ရဲ့ row အားလုံး・column အားလုံးကို ယူပါ

```sql
-- ① name နဲ့ class ကိုပဲ ယူပါ

-- ② name AS 氏名, score AS 点数 နဲ့ ယူပါ

-- ③ Column အားလုံး・row အားလုံးကို ယူပါ
```

## ပုစ္ဆာ 2（WHERE）：သတ်မှတ်ချက်နဲ့ စစ်ထုတ်ခြင်း

1. `class` က `'B'` ဖြစ်တဲ့ ကျောင်းသားတွေကို ယူပါ
2. `age` က 18 နှစ်နှင့်အထက်ဖြစ်ပြီး `score` က 80 မှတ်နှင့်အထက် ရတဲ့ ကျောင်းသားတွေကို ယူပါ
3. `class` က `'A'` ဒါမှမဟုတ် `'C'` ဖြစ်တဲ့ ကျောင်းသားတွေကို `IN` သုံးပြီး ယူပါ
4. `name` ထဲမှာ「郎」ဆိုတဲ့ စာလုံး ပါတဲ့ ကျောင်းသားတွေကို `LIKE` သုံးပြီး ယူပါ

```sql

-- ④
```

## ပုစ္ဆာ 3（ORDER BY / LIMIT）：အစီအစဉ် စီခြင်းနဲ့ အရေအတွက် ကန့်သတ်ခြင်း

1. ကျောင်းသားအားလုံးကို `score` အမြင့်ဆုံးမှ အနိမ့်ဆုံးသို့（ကြီးစဉ်ငယ်လိုက်）စီပြီး ယူပါ
2. အပေါ်ကထဲကမှ ထိပ်ဆုံး 3 ယောက်ကိုပဲ ယူပါ（`LIMIT` ကို သုံးပါ）
3. `class` ကို ငယ်စဉ်ကြီးလိုက်၊ `class` တူရင် `score` ကို ကြီးစဉ်ငယ်လိုက် စီပြီး ယူပါ

```sql
-- ①

-- ②

-- ③
```

**② အတွက် မျှော်မှန်းထားတဲ့ ရလဒ်（ထိပ်ဆုံး 3 ယောက်၊ 点 ဆိုသည်မှာ အမှတ်ဖြစ်သည်）：**
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

## ပုစ္ဆာ 4（Aggregate function）：တစ်ခုလုံးရဲ့ စာရင်းအင်းကို ရှာခြင်း

1. ကျောင်းသား အရေအတွက်ကို `COUNT(*)` နဲ့ ရှာပါ
2. `score` ရဲ့ စုစုပေါင်းအမှတ်၊ ပျမ်းမျှအမှတ်၊ အမြင့်ဆုံးအမှတ်နဲ့ အနိမ့်ဆုံးအမှတ်တို့ကို အသီးသီး「合計点」（စုစုပေါင်းအမှတ်）၊「平均点」（ပျမ်းမျှအမှတ်）၊「最高点」（အမြင့်ဆုံးအမှတ်）၊「最低点」（အနိမ့်ဆုံးအမှတ်）ဆိုတဲ့ alias တွေနဲ့ SQL တစ်ခုတည်းမှာ စုပြီး ယူပါ

```sql
-- ① အရေအတွက်ကို ယူပါ

-- ② ပေါင်းလဒ်・ပျမ်းမျှ・အမြင့်ဆုံး・အနိမ့်ဆုံးကို စုပြီး ယူပါ
```

## ပုစ္ဆာ 5（အဆင့်မြင့်）：WHERE + GROUP BY + ORDER BY ကို ပေါင်းစပ်ခြင်း

1. `score` 60 မှတ်နှင့်အထက် ရတဲ့ ကျောင်းသားတွေကိုပဲ ယူပြီး `class` အလိုက် ပျမ်းမျှအမှတ်（`AVG`）နဲ့ ကျောင်းသားအရေအတွက်（`COUNT`）ကို ရှာကာ ပျမ်းမျှအမှတ် အမြင့်ဆုံးမှ အနိမ့်ဆုံးသို့ စီပါ
2. Class `'A'` ကျောင်းသားတွေထဲမှာ အမှတ် အမြင့်ဆုံး ကျောင်းသား တစ်ယောက်ကိုပဲ ယူပါ（`WHERE` + `ORDER BY` + `LIMIT` ကို ပေါင်းစပ်ပါ）

```sql
-- ① 60 မှတ်နှင့်အထက် ရတဲ့ ကျောင်းသားတွေကိုသာ ထည့်တွက်ပြီး class အလိုက် ပျမ်းမျှအမှတ်နဲ့ ကျောင်းသားအရေအတွက်ကို ပျမ်းမျှအမှတ် အမြင့်ဆုံးမှ အနိမ့်ဆုံးသို့ စီပါ

-- ② class = 'A' ထဲမှာ အမှတ် အမြင့်ဆုံး ကျောင်းသား တစ်ယောက်ကိုပဲ
```

**အရိပ်အမြွက်：**
- ① ကို `WHERE` → `GROUP BY` → `ORDER BY` အစီအစဉ်နဲ့ ရေးပါ（အမှန်တကယ် လုပ်ဆောင်သည့် အစီအစဉ်အတွက် သင်ချိန် 07 ရဲ့ အနှစ်ချုပ်ကို ကြည့်ပါ）
- ② မှာ `ORDER BY score DESC LIMIT 1` ကို သုံးပါ
