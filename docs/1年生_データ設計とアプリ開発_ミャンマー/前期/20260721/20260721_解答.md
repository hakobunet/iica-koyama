# သင်ချိန် 07 လေ့ကျင့်ခန်း｜အဖြေ နမူနာ

> 🇯🇵 မူရင်း (ဂျပန်ဘာသာဖြင့်): [20260721_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260721/20260721_解答.md>) <!-- original-ja-link -->

`students` table ရဲ့ ဒေတာ（သင်ချိန် 07 ရဲ့ သင်ခန်းစာကို ကြည့်ပါ）ကို အခြေခံထားတဲ့ အဖြေ နမူနာပါ။

---

## ပုစ္ဆာ 1（SELECT အခြေခံ）

### အဖြေ

```sql
-- ① name နဲ့ class ကိုပဲ ယူပါ
SELECT name, class FROM students;

-- ② name ကို 氏名（အမည်）、score ကို 点数（အမှတ်）လို့ အမည်ပေးပြီး ယူပါ
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ Column အားလုံး・row အားလုံးကို ယူပါ
SELECT * FROM students;
```

---

## ပုစ္ဆာ 2（WHERE）

### အဖြေ

```sql
-- ① class က 'B' ဖြစ်တဲ့ ကျောင်းသား
SELECT * FROM students WHERE class = 'B';

-- ② age က 18 နှစ်နှင့်အထက်ဖြစ်ပြီး score က 80 မှတ်နှင့်အထက်
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class က 'A' ဒါမှမဟုတ် 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name ထဲမှာ「郎」ပါတယ်
SELECT * FROM students WHERE name LIKE '%郎%';
```

**ရလဒ်（ကိုးကားရန်）：**
- ①：山田次郎(91)、佐藤三郎(58)、吉田健太(88)
- ②：田中太郎(85)、山田次郎(91)、渡辺一郎(95)、吉田健太(88)
- ③：田中太郎・鈴木花子・伊藤美咲・山本麻衣（A）、渡辺一郎・加藤幸子・中村龍一（C）
- ④：田中太郎・山田次郎・佐藤三郎・渡辺一郎（4 ယောက်）

---

## ပုစ္ဆာ 3（ORDER BY / LIMIT）

### အဖြေ

```sql
-- ① score ကို ကြီးစဉ်ငယ်လိုက်နဲ့ အားလုံး
SELECT * FROM students ORDER BY score DESC;

-- ② ထိပ်ဆုံး 3 ယောက်ကိုပဲ
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class ကို ငယ်စဉ်ကြီးလိုက်၊ class တူရင် score ကို ကြီးစဉ်ငယ်လိုက်
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**ရလဒ်（ကိုးကားရန်）：**

②（点 = အမှတ်）
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

③
```
[A] 田中太郎85, 伊藤美咲78, 鈴木花子72, 山本麻衣67
[B] 山田次郎91, 吉田健太88, 佐藤三郎58
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## ပုစ္ဆာ 4（Aggregate function）

### အဖြေ

```sql
-- ① အရေအတွက်
SELECT COUNT(*) FROM students;

-- ② ပေါင်းလဒ်・ပျမ်းမျှ・အမြင့်ဆုံး・အနိမ့်ဆုံးကို စုပြီး ယူပါ
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**ရလဒ်（ကိုးကားရန်）：**
- ①：10 ယောက်
- ②：合計点（စုစုပေါင်းအမှတ်）752 ／ 平均点（ပျမ်းမျှအမှတ်）75.2 ／ 最高点（အမြင့်ဆုံးအမှတ်）95 ／ 最低点（အနိမ့်ဆုံးအမှတ်）45

---

## ပုစ္ဆာ 5（အဆင့်မြင့်）

### အဖြေ

```sql
-- ① 60 မှတ်နှင့်အထက် ကျောင်းသားတွေကို ယူပြီး class အလိုက် ပျမ်းမျှ အမှတ်・အရေအတွက်ကို ပျမ်းမျှ အမှတ် အများမှ အနည်းသို့ စီပါ
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② class = 'A' ထဲမှာ အမှတ် အမြင့်ဆုံး ကျောင်းသား တစ်ယောက်ကိုပဲ
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**ရလဒ်（ကိုးကားရန်）：**

①（60 မှတ်အောက် ရတဲ့ 佐藤三郎・加藤幸子 တို့ကို ဖယ်ထားပါတယ်။ 平均点 = ပျမ်းမျှအမှတ်၊ 人数 = လူဦးရေ）
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②（点 = အမှတ်）
```
田中太郎 85点
```
