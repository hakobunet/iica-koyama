> 🇯🇵 မူရင်း (ဂျပန်ဘာသာဖြင့်): [20260630_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260630/20260630_演習.md>) <!-- original-ja-link -->

`src/index.php` ကို ဖန်တီးပြီး ပုစ္ဆာတစ်ခုချင်းစီရဲ့ code ကို ရေးကာ `php -S localhost:8000` နဲ့ အလုပ်လုပ်မလုပ် စစ်ကြည့်ရအောင်။

## ပုစ္ဆာ 1：ကိုယ့်ကိုယ်ကို မိတ်ဆက်စာ ပြသခြင်း

Variable `$name`・`$age`・`$hobby` တို့ကို သတ်မှတ်ပြီး အောက်ပါအတိုင်း ပေါ်လာမယ့် PHP file ကို ရေးပါ။

**မျှော်မှန်းထားတဲ့ output နမူနာ（browser မှာ ပြသမယ်）:** 「名前」＝ အမည်၊「年齢」＝ အသက်၊「歳」＝ နှစ်၊「趣味」＝ ဝါသနာ၊「プログラミング」＝ ပရိုဂရမ်ရေးခြင်း၊「田中太郎」＝ လူအမည်
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

စည်းကမ်းချက်：
- Variable တွေကို `$` နဲ့ မဖြစ်မနေ စပါ
- String ထဲမှာ variable ကို ထည့်ရေးတဲ့ `"..."` ပုံစံနဲ့ output ထုတ်ပါ

```php
<?php
// ဒီမှာ ရေးပါ


?>
```

---

## ပုစ္ဆာ 2：Array ကို HTML list အဖြစ် ပြသခြင်း

`$fruits = ["りんご", "みかん", "ぶどう", "バナナ"]` ကို `foreach` နဲ့ loop ပတ်ပြီး `<ul>` / `<li>` tag တွေကို သုံးကာ HTML အဖြစ် ပြသပါ။

**မျှော်မှန်းထားတဲ့ output（browser မှာ ပြသမယ်）:** 「りんご」＝ ပန်းသီး၊「みかん」＝ လိမ္မော်သီး၊「ぶどう」＝ စပျစ်သီး၊「バナナ」＝ ငှက်ပျောသီး
```
• りんご
• みかん
• ぶどう
• バナナ
```

စည်းကမ်းချက်：
- `foreach` ကို သုံးရမယ်
- HTML ရဲ့ `<ul>` နဲ့ `<li>` tag တွေကို echo နဲ့ output ထုတ်ရမယ်

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// ဒီမှာ ရေးပါ


?>
```

## ပုစ္ဆာ 3：1 ကနေ 10 အထိ ပေါင်းလဒ်ကို တွက်ခြင်း

`for` loop ကို သုံးပြီး 1〜10 အထိ ကိန်းပြည့်အားလုံးကို ပေါင်းထားတဲ့ ပေါင်းလဒ်ကို output ထုတ်ပါ။

**မျှော်မှန်းထားတဲ့ output:** 「合計」＝ ပေါင်းလဒ်
```
合計: 55
```

စည်းကမ်းချက်：
- `for` loop ကို သုံးရမယ်
- ပေါင်းလဒ်ကို သိမ်းမယ့် variable `$total` ကို သုံးရမယ်

```php
<?php
$total = 0;

// ဒီမှာ ရေးပါ


echo "合計: " . $total;
?>
```
