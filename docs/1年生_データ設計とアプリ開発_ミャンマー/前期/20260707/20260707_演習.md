## Part 1｜Array・Associative array

### ပုစ္ဆာ 1-1：Array ကို စုစည်းတွက်ချက်ခြင်း

စာမေးပွဲ အမှတ်တွေ ပါတဲ့ array ကနေ ပေါင်းလဒ်・ပျမ်းမျှ・အမြင့်ဆုံးအမှတ်・အနိမ့်ဆုံးအမှတ်နဲ့「အောင်သူ အရေအတွက်（70 မှတ်နှင့်အထက်）」ကို ရှာပါ။

```php
<?php
$scores = [85, 42, 91, 67, 78, 55, 93, 70, 61, 88];

// ① စုစုပေါင်း အမှတ်ကို output ထုတ်ပါ

// ② ပျမ်းမျှ အမှတ်ကို output ထုတ်ပါ（ဒသမ ၁ နေရာအထိ）
//    အရိပ်အမြွက်: number_format($avg, 1)

// ③ အမြင့်ဆုံးအမှတ်နဲ့ အနိမ့်ဆုံးအမှတ်ကို output ထုတ်ပါ

// ④ 70 မှတ်နှင့်အထက် ရတဲ့ အောင်သူ အရေအတွက်ကို output ထုတ်ပါ
//    အရိပ်အမြွက်: array_filter + count
?>
```

### ပုစ္ဆာ 1-2：Associative array တွေရဲ့ array ကို ကိုင်တွယ်ခြင်း

အောက်ပါ ကျောင်းသား ဒေတာထဲကနေ စည်းကမ်းချက်နဲ့ ကိုက်ညီတဲ့ ကျောင်းသားတွေကို ရွေးထုတ်ပြီး ပြသပါ။ ဥပမာထဲက 「Aクラス」ဆိုတာ A အတန်း၊ 「85点」ဆိုတာ 85 မှတ်လို့ ဆိုလိုပါတယ်။

```php
<?php
$students = [
    ["id" => 1, "name" => "田中太郎", "class" => "A", "score" => 85],
    ["id" => 2, "name" => "鈴木花子", "class" => "B", "score" => 62],
    ["id" => 3, "name" => "山田次郎", "class" => "A", "score" => 91],
    ["id" => 4, "name" => "佐藤三郎", "class" => "B", "score" => 47],
    ["id" => 5, "name" => "伊藤美咲", "class" => "A", "score" => 78],
];

// ① ကျောင်းသားအားလုံးကို「ID:1 田中太郎 (Aクラス) 85点」ပုံစံနဲ့ output ထုတ်ပါ

// ② Class A ကျောင်းသားတွေကိုပဲ output ထုတ်ပါ

// ③ 80 မှတ်နှင့်အထက် ရတဲ့ ကျောင်းသားတွေကိုပဲ output ထုတ်ပါ
?>
```

## Part 2｜Condition ခွဲခြင်း・Function

### ပုစ္ဆာ 2-1：အဆင့်သတ်မှတ်တဲ့ function ဖန်တီးခြင်း

အမှတ်ကို လက်ခံပြီး အဆင့် string ကို ပြန်ပေးတဲ့ function `getGrade()` ကို ဖန်တီးပါ။ အောက်ပါ output ထဲက 「点」ဆိုတာ အမှတ်၊ 「評価」ဆိုတာ အဆင့်သတ်မှတ်ချက်လို့ ဆိုလိုပါတယ်။

| --- | --- |

| 80 နှင့်အထက် | A |
| 70 နှင့်အထက် | B |
| 60 နှင့်အထက် | C |
| 60 အောက် | D |

```php
<?php
function getGrade(int $score): string {
    // ဒီမှာ if/elseif ကို ရေးပါ

}

// အလုပ်လုပ်မလုပ် စစ်ဆေးခြင်း
```

## Part 3｜Form နှင့် POST

### ပုစ္ဆာ 3-1：စုံစမ်းမေးမြန်းရေး form ဖန်တီးခြင်း

`contact.php` ကို file တစ်ခုတည်းနဲ့ ဖန်တီးပါ။ စာမျက်နှာခေါင်းစဉ် 「問い合わせ」ဆိုတာ စုံစမ်းမေးမြန်းခြင်းလို့ ဆိုလိုပါတယ်။

**သတ်မှတ်ချက်：**
- ထည့်ရမယ့် အကွက်များ：အမည်・email လိပ်စာ・message
- ပို့ပြီးနောက်「〇〇さんからのお問い合わせを受け付けました」（〇〇 ထံမှ စုံစမ်းမေးမြန်းချက်ကို လက်ခံရရှိပါပြီ）လို့ ပြသပါ
- XSS ကာကွယ်ဖို့ `htmlspecialchars()` ကို မဖြစ်မနေ သုံးပါ

```php
<?php
// ▼ contact.php ထဲမှာ ရေးပါ

$name    = "";
$email   = "";
$message = "";
$sent    = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // ① ဒေတာကို ထုတ်ယူပါ（null ဖြစ်ရင် ?? "" နဲ့ အလွတ် string ကို သုံးပါ）

    // ② htmlspecialchars ကို သုံးပြီး ပြောင်းလဲပါ

    $sent = true;
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>問い合わせ</title></head>
<body>
<?php if ($sent): ?>
  <!-- ပို့ပြီးကြောင်း message -->
<?php else: ?>
  <!-- Form -->
<?php endif; ?>
</body>
</html>
```

### ပုစ္ဆာ 3-2：Validation ပါတဲ့ form ဖန်တီးခြင်း

`register.php` ကို ဖန်တီးပြီး အောက်ပါ validation တွေကို ထည့်သွင်းပါ။ 「登録」ဆိုတာ မှတ်ပုံတင်ခြင်း၊ 「名前」ဆိုတာ အမည်၊ 「年齢」ဆိုတာ အသက်လို့ ဆိုလိုပါတယ်။

**Validation စည်းကမ်းချက်：**
- အမည်：မဖြစ်မနေ ထည့်ရမယ်・စာလုံး 50 အတွင်း
