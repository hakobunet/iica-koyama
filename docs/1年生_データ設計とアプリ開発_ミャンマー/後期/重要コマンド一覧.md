# အရေးကြီး Command စာရင်း

> 🇯🇵 မူရင်း (ဂျပန်ဘာသာဖြင့်): [重要コマンド一覧.md](<../../1年生_データ設計とアプリ開発/後期/重要コマンド一覧.md>) <!-- original-ja-link -->

> Command တွေကို **VS Code ရဲ့ terminal** မှာ ရိုက်ပါ။
> Docker Desktop ကို အရင်ဖွင့်ပြီးမှ သုံးပါ။

---

## စတင်ခြင်း・ရပ်ခြင်း

### စတင်ခြင်း (mysql → laravel အစီအစဉ်အတိုင်း)

```powershell
docker compose up -d
```

### ရပ်ခြင်း (laravel → mysql အစီအစဉ်အတိုင်း)

```powershell
docker compose down
```

စတင်ပြီးရင် browser မှာ ဖွင့်ကြည့်ပါ။

| URL | ကြည့်လို့ရတဲ့အရာ |
|-----|------------|
| http://localhost:8000 | Laravel (ဖန်တီးနေတဲ့ App) |
| http://localhost:8080 | phpMyAdmin (database) |

---

## File ဖန်တီးခြင်း

laravel folder မှာ ရိုက်ပါ။

### Migration file ဖန်တီးခြင်း

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### Model ဖန်တီးခြင်း

```powershell
docker compose exec laravel php artisan make:model Todo
```

### Controller ဖန်တီးခြင်း

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## Database ကို ကိုင်တွယ်ခြင်း

laravel folder မှာ ရိုက်ပါ။

### Table ဖန်တီးခြင်း

```powershell
docker compose exec laravel php artisan migrate
```
