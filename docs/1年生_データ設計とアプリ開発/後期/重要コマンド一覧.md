# 重要コマンド一覧

## Docker

> Docker Desktop を起動して、左下が **Engine running** になっていることを確認してから使います。
> コマンドは **VS Code のターミナル** で打ちます（メニューの `ターミナル` → `新しいターミナル`）。
> `mysql` フォルダか `laravel` フォルダに **移動してから** 実行します。

### よく使うコマンド

| コマンド | 何をする？ | どのフォルダで？ |
|---------|----------|---------------|
| `docker compose up -d` | コンテナを **起動** する | mysql → laravel の順 |
| `docker compose down` | コンテナを **止める**（データは消えない） | laravel → mysql の順 |
| `docker compose ps` | 動いているコンテナを **確認** する | mysql / laravel |
| `docker compose logs -f` | ログ（動きの記録）を **見つづける**。`Ctrl + C` で見るのをやめる | mysql / laravel |
| `docker compose exec laravel <コマンド>` | laravel コンテナの **中で** コマンドを動かす | laravel |
| `docker --version` | Docker が入っているか確認する | どこでも |

### 起動する（mysql → laravel の順）

mysql フォルダ → laravel フォルダの順に、それぞれで実行します。

```powershell
docker compose up -d
```

| 開くURL | 表示されるもの |
|---------|--------------|
| http://localhost:8000 | Laravel |
| http://localhost:8080 | phpMyAdmin |

### 止める（laravel → mysql の順）

laravel フォルダ → mysql フォルダの順に、それぞれで実行します。

```powershell
docker compose down
```

### コンテナの中でコマンドを動かす（exec）

`php artisan` は、laravel コンテナの中で動かします。前に `docker compose exec laravel` をつけます。

```powershell
docker compose exec laravel php artisan migrate
docker compose exec laravel php artisan migrate:fresh --seed
docker compose exec laravel php artisan make:controller TodoController
```

| コマンド | 何をする？ |
|---------|----------|
| `php artisan migrate` | まだ実行していないマイグレーションファイルを読んで、**テーブルを作る・変更する**。新しくマイグレーションファイルを作ったら実行する |
| `php artisan migrate:fresh --seed` | テーブルを **全部消して作り直し**、Seeder で **最初のデータを入れ直す**。データがぐちゃぐちゃになったときや、Seeder を書きかえたときに使う（**入れたデータは消える**） |
| `php artisan make:controller TodoController` | `TodoController` という名前の **コントローラーのファイルを作る**（くわしくは下の「ファイルを作る」） |

| 部分 | 意味 |
|-----|------|
| `docker compose exec` | コンテナの中で、次のコマンドを動かして |
| `laravel` | どのコンテナで？（laravel コンテナ） |
| `php artisan migrate` | 動かしたいコマンド |

### ファイルを作る（make）

laravel フォルダで実行します。作られたファイルは `laravel/src` の中に入ります。

#### マイグレーションファイルを作る

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

- 名前は `create_〇〇_table`（〇〇はテーブル名・**複数形**）
- 列を足すときは `add_〇〇_to_△△_table`（例：`add_category_to_todos_table`）
- できる場所：`src/database/migrations/`

#### コントローラーを作る

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

- 名前は `〇〇Controller`（〇〇は **単数形**・最初の文字は大文字）
- できる場所：`src/app/Http/Controllers/`

#### モデルを作る

```powershell
docker compose exec laravel php artisan make:model Todo
```

- 名前は **単数形**・最初の文字は大文字（テーブル `todos` → モデル `Todo`）
- できる場所：`src/app/Models/`

### 注意が必要なコマンド

| コマンド | 何をする？ |
|---------|----------|
| `docker compose down -v` | コンテナを止めて、**データベースの中身も全部消す**。最初からやり直したいときだけ使う（mysql フォルダで） |

### うまくいかないとき

| 症状 | 対処 |
|------|------|
| `network practice-network declared as external, but could not be found` | mysql を先に起動していない → mysql フォルダで `docker compose up -d` |
| `port is already allocated` | XAMPP の MySQL や Apache が動いている → XAMPP Control Panel で Stop |
| `no configuration file provided: not found` | フォルダの移動を忘れている → `cd` で mysql か laravel フォルダに移動 |
| `error during connect` / `docker daemon is not running` | Docker Desktop が起動していない → 起動して **Engine running** を確認 |
