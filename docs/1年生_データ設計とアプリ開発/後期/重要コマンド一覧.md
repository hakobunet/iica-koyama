# 重要コマンド一覧

> コマンドは **VS Code のターミナル** で打ちます。
> Docker Desktop を起動してから使いましょう。

---

## 起動する・止める

| コマンド | 何をする？ |
|---------|----------|
| `docker compose up -d` | 起動する（**mysql → laravel** の順） |
| `docker compose down` | 止める（**laravel → mysql** の順） |

起動したら、ブラウザで開きます。

| URL | 見られるもの |
|-----|------------|
| http://localhost:8000 | Laravel（作っているアプリ） |
| http://localhost:8080 | phpMyAdmin（データベース） |

---

## ファイルを作る

laravel フォルダで打ちます。

| コマンド | 何をする？ |
|---------|----------|
| `docker compose exec laravel php artisan make:migration create_todos_table` | マイグレーションファイルを作る |
| `docker compose exec laravel php artisan make:model Todo` | モデルを作る |
| `docker compose exec laravel php artisan make:controller TodoController` | コントローラーを作る |

---

## データベースを動かす

laravel フォルダで打ちます。

| コマンド | 何をする？ |
|---------|----------|
| `docker compose exec laravel php artisan migrate` | テーブルを作る |
