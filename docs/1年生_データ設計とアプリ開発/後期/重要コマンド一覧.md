# 重要コマンド一覧

> コマンドは **VS Code のターミナル** で打ちます。
> Docker Desktop を起動してから使いましょう。

---

## 起動する・止める

### 起動する（mysql → laravel の順）

```powershell
docker compose up -d
```

### 止める（laravel → mysql の順）

```powershell
docker compose down
```

起動したら、ブラウザで開きます。

| URL | 見られるもの |
|-----|------------|
| http://localhost:8000 | Laravel（作っているアプリ） |
| http://localhost:8080 | phpMyAdmin（データベース） |

---

## ファイルを作る

laravel フォルダで打ちます。

### マイグレーションファイルを作る

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### モデルを作る

```powershell
docker compose exec laravel php artisan make:model Todo
```

### コントローラーを作る

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## データベースを動かす

laravel フォルダで打ちます。

### テーブルを作る

```powershell
docker compose exec laravel php artisan migrate
```
