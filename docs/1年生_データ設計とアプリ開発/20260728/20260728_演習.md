## 演習2：INSERT / UPDATE / DELETE

```sql
-- ① 次のユーザーを追加してください
--    名前: 中村健二, メール: nakamura@example.com
--    期待する出力: id=4 として中村健二が追加される

-- ② products テーブルに「USBハブ」（価格: 2800円）を追加してください
--    期待する出力: id=4 として USBハブ(2800円) が追加される

-- ③ 田中太郎が USBハブ を 3個 注文した記録を orders に追加してください
--    ヒント: まず田中太郎の id と USBハブの id を SELECT で確認する
--    （2手順でもOK。1文で書きたい人は資料8章「サブクエリ」を参照）
--    期待する出力: id=6 の注文として (user_id=1, product_id=4, quantity=3) が追加される

-- ④ ノートPC の価格を 95000円 に更新してください
--    ヒント: SELECT で確認してから UPDATE する
--    期待する出力: ノートPCの price が 98000 → 95000 に変わる

-- ⑤ 追加した中村健二の注文データがあれば削除し、次に中村健二自体を削除してください
--    ヒント: 外部キー制約があるため、orders を先に削除する必要があります
--    ヒント: 中村健二の id が分からなくても、資料8章「サブクエリ」の書き方を使えば
--    (SELECT id FROM users WHERE name = '中村健二') で1文にまとめられる
--    期待する出力: 中村健二の注文は0件なので1つ目のDELETEは対象0件、
--    2つ目のDELETEで中村健二(id=4)が削除される
```
