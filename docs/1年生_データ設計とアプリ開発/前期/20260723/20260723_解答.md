# コマ08 演習｜解答例

`students` テーブルの初期データ（コマ07資料参照）をもとにした解答例です。
各問題は、特に断りがない限り「初期データからの操作」として独立に考えます。

```
初期データ（10件）
 id │ name     │ age │ class │ score
────┼──────────┼─────┼───────┼──────
  1 │ 田中太郎 │ 18  │ A     │ 85
  2 │ 鈴木花子 │ 19  │ A     │ 72
  3 │ 山田次郎 │ 18  │ B     │ 91
  4 │ 佐藤三郎 │ 20  │ B     │ 58
  5 │ 伊藤美咲 │ 18  │ A     │ 78
  6 │ 渡辺一郎 │ 19  │ C     │ 95
  7 │ 加藤幸子 │ 18  │ C     │ 45
  8 │ 吉田健太 │ 20  │ B     │ 88
  9 │ 山本麻衣 │ 19  │ A     │ 67
 10 │ 中村龍一 │ 18  │ C     │ 73
```

---

## 問題1（INSERT）

### 答え

```sql
-- ① 新入生Fを1件追加
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② 新入生G・Hを1つのINSERT文で追加
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**結果（参考）：**
- ①：`id=11` として「新入生F」が追加される（`id` は AUTO_INCREMENT のため指定不要）
- ②：`id=12`「新入生G」、`id=13`「新入生H」が同時に追加される

---

## 問題2（UPDATE）

### 答え

```sql
-- ① id=3 の生徒の class を 'S' に更新
UPDATE students SET class = 'S' WHERE id = 3;

-- ② class が 'B' の生徒全員の score に +10
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**結果（参考）：**
- ①：山田次郎（id=3）の `class` が `B` → `S` に変わる
- ②：class='B' の3名が対象
  - 山田次郎：91 → 101
  - 佐藤三郎：58 → 68
  - 吉田健太：88 → 98

③ の説明：
> `WHERE` を付け忘れて `UPDATE students SET score = 0;` を実行すると、`students` テーブルの**全10件**が対象になり、全員の `score` が問答無用で 0点になってしまう。`UPDATE`/`DELETE` は実行前に必ず `WHERE` を確認する必要がある。

---

## 問題3（DELETE）

### 答え

```sql
-- ① id=8 の生徒を削除
DELETE FROM students WHERE id = 8;

-- ② score が 40点未満の生徒を全員削除
DELETE FROM students WHERE score < 40;

-- ③ ②を実行する前に、対象行をSELECTで確認する
SELECT * FROM students WHERE score < 40;
```

**結果（参考）：**
- ①：吉田健太（id=8）が削除される
- ②：初期データの最低点は 45点（加藤幸子）なので、`score < 40` に該当する生徒は**0件**。つまりこの `DELETE` は何も削除しない（「対象0件」も正しい実行結果）
- ③：②の `DELETE` の前に必ず実行し、削除される行が意図通りかを目で確認してから `DELETE` を実行する（資料4章「安全なUPDATE/DELETEのやり方」参照）
