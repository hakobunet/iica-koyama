# Key Commands

> 🇯🇵 Original (Japanese version): [重要コマンド一覧.md](<../../1年生_データ設計とアプリ開発/後期/重要コマンド一覧.md>) <!-- original-ja-link -->

> Type the commands in the **VS Code terminal**.
> Start Docker Desktop before using them.

---

## Starting and Stopping

### Start (mysql first, then laravel)

```powershell
docker compose up -d
```

### Stop (laravel first, then mysql)

```powershell
docker compose down
```

Once everything is running, open these in your browser.

| URL | What you'll see |
|-----|------------|
| http://localhost:8000 | Laravel (the app you're building) |
| http://localhost:8080 | phpMyAdmin (the database) |

---

## Creating Files

Run these commands from the laravel folder.

### Create a migration file

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### Create a model

```powershell
docker compose exec laravel php artisan make:model Todo
```

### Create a controller

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## Working with the Database

Run these commands from the laravel folder.

### Create the tables

```powershell
docker compose exec laravel php artisan migrate
```
