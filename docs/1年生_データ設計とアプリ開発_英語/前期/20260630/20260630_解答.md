## Problem 1 Answer

```php
<?php
$name  = "田中太郎";
$age   = 20;
$hobby = "プログラミング";

echo "名前：{$name}<br>";
echo "年齢：{$age}歳<br>";
echo "趣味：{$hobby}<br>";
?>
```

---

## Problem 2 Answer

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

echo "<ul>";
foreach ($fruits as $fruit) {
    echo "<li>{$fruit}</li>";
}
echo "</ul>";
?>
```

---

## Problem 3 Answer

```php
<?php
$total = 0;

for ($i = 1; $i <= 10; $i++) {
    $total += $i;
}

echo "合計: " . $total;  // → 合計: 55 (Total: 55)
?>
```

---

## Problem 4 Answer (Advanced)

```php
<?php
for ($dan = 2; $dan <= 5; $dan++) {
    for ($i = 1; $i <= 9; $i++) {
        echo "{$dan}×{$i}=" . ($dan * $i) . "  ";
    }
    echo "<br>";
}
?>
```
