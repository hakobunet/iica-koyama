## Problem 1: Display a Self-Introduction

Define the variables `$name`, `$age`, and `$hobby`, and write a PHP file that displays the following.

**Expected output (shown in the browser):**
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

Requirements:
- Variables must always start with `$`
- Use a double-quoted string (`"..."`) to embed the variables in the output

```php
<?php
// Write your code here


?>
```

**Expected output (shown in the browser):**
```
• りんご
• みかん
• ぶどう
• バナナ
```

Requirements:
- Use `foreach`
- Output the HTML `<ul>` and `<li>` tags with echo

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// Write your code here


?>
```

## Problem 3: Calculate the Sum from 1 to 10

Use a `for` loop to add up all the integers from 1 to 10 and output the total.

**Expected output:**
```
合計: 55
```

Requirements:
- Use a `for` loop
- Use a variable `$total` to store the total

```php
<?php
$total = 0;

// Write your code here


echo "合計: " . $total;
?>
```
