## Exercise 2: INSERT / UPDATE / DELETE

```sql
-- ① Add the following user
--    Name: 中村健二, Email: nakamura@example.com
--    Expected output: 中村健二 is added with id=4

-- ② Add "USBハブ" (price: 2800 yen) to the products table
--    Expected output: USBハブ (2800 yen) is added with id=4

-- ③ Add a record to orders showing that 田中太郎 ordered 3 units of USBハブ
--    Hint: First, use SELECT to check the id of 田中太郎 and the id of USBハブ
--    (Doing it in 2 steps is OK. If you want to write it in one statement, see Chapter 8 "Subqueries" in the materials)
--    Expected output: an order with id=6 is added as (user_id=1, product_id=4, quantity=3)

-- ④ Update the price of ノートPC to 95000 yen
--    Hint: Check with SELECT first, then run UPDATE
--    Expected output: the price of ノートPC changes from 98000 to 95000

-- ⑤ Delete any orders belonging to the user 中村健二 you added, then delete 中村健二
--    Hint: Because of the foreign key constraint, you need to delete from orders first
--    Hint: Even if you don't know 中村健二's id, you can use the approach from Chapter 8 "Subqueries" in the materials
--    and combine it into one statement with (SELECT id FROM users WHERE name = '中村健二')
--    Expected output: 中村健二 has 0 orders, so the first DELETE affects 0 rows,
--    and the second DELETE deletes 中村健二 (id=4)
```
