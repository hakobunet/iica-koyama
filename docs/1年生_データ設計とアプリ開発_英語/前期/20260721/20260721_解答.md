# Session 07 Exercises | Sample Answers

> 🇯🇵 Original (Japanese version): [20260721_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260721/20260721_解答.md>) <!-- original-ja-link -->

These sample answers are based on the data in the `students` table (see the Session 07 handout).

---

## Problem 1 (SELECT Basics)

### Answer

```sql
-- ① Get only name and class
SELECT name, class FROM students;

-- ② Get name AS 氏名 and score AS 点数
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ Get all columns and all rows
SELECT * FROM students;
```

---

## Problem 2 (WHERE)

### Answer

```sql
-- ① Students whose class is 'B'
SELECT * FROM students WHERE class = 'B';

-- ② Students aged 18 or older with a score of 80 or higher
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class is 'A' or 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name contains 「郎」
SELECT * FROM students WHERE name LIKE '%郎%';
```

**Results (for reference):**
- ①: 山田次郎 (91), 佐藤三郎 (58), 吉田健太 (88)
- ②: 田中太郎 (85), 山田次郎 (91), 渡辺一郎 (95), 吉田健太 (88)
- ③: 田中太郎, 鈴木花子, 伊藤美咲, 山本麻衣 (A); 渡辺一郎, 加藤幸子, 中村龍一 (C)
- ④: 田中太郎, 山田次郎, 佐藤三郎, 渡辺一郎 (4 students)

## Problem 3 (ORDER BY / LIMIT)

### Answer

```sql
-- ① Everyone, sorted by score in descending order
SELECT * FROM students ORDER BY score DESC;

-- ② Only the top 3
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class in ascending order; within the same class, score in descending order
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**Results (for reference):**

②
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

③
```
[A] 田中太郎85, 伊藤美咲78, 鈴木花子72, 山本麻衣67
[B] 山田次郎91, 吉田健太88, 佐藤三郎58
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## Problem 4 (Aggregate Functions)

### Answer

```sql
-- ① Number of students
SELECT COUNT(*) FROM students;

-- ② Get the total, average, highest, and lowest all at once
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**Results (for reference):**
- ①: 10 students
- ②: 合計点 (total) 752 / 平均点 (average) 75.2 / 最高点 (highest) 95 / 最低点 (lowest) 45

---

## Problem 5 (Advanced)

### Answer

```sql
-- ① For students with a score of 60 or higher, get the average score and count per class, highest average first
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② Get only the one student with the highest score where class = 'A'
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**Results (for reference):**

① (佐藤三郎 and 加藤幸子, who scored below 60, are excluded)
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②
```
田中太郎 85点
```
