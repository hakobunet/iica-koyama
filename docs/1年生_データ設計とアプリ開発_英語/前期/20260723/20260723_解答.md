## Question 1 (INSERT)

### Answer

```sql
-- ① Add one record for 新入生F
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② Add 新入生G and 新入生H with a single INSERT statement
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**Result (for reference):**
- ①: "新入生F" is added with `id=11` (`id` is AUTO_INCREMENT, so you don't need to specify it)
- ②: "新入生G" (`id=12`) and "新入生H" (`id=13`) are added at the same time

## Question 2 (UPDATE)

### Answer

```sql
-- ① Update the class of the student with id=3 to 'S'
UPDATE students SET class = 'S' WHERE id = 3;

-- ② Add 10 to the score of every student whose class is 'B'
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**Result (for reference):**
- ①: The `class` of 山田次郎 (id=3) changes from `B` to `S`
- ②: The 3 students with class='B' are affected
  - 山田次郎: 91 → 101
  - 佐藤三郎: 58 → 68
  - 吉田健太: 88 → 98

Explanation for ③:
> If you forget the `WHERE` clause and run `UPDATE students SET score = 0;`, **all 10 rows** in the `students` table are updated, and everyone's `score` is set to 0. Always check the `WHERE` clause before running an `UPDATE` or `DELETE` statement.

---

## Question 3 (DELETE)

### Answer

```sql
-- ① Delete the student with id=8
DELETE FROM students WHERE id = 8;

-- ② Delete every student whose score is less than 40 points
DELETE FROM students WHERE score < 40;

-- ③ Before running ②, check the target rows with SELECT
SELECT * FROM students WHERE score < 40;
```

**Result (for reference):**
- ①: 吉田健太 (id=8) is deleted
- ②: The lowest score in the initial data is 45 points (加藤幸子), so **0 students** match `score < 40`. In other words, this `DELETE` deletes nothing ("0 rows affected" is also a correct result)
- ③: Always run this before the `DELETE` in ②, visually check that the rows are the ones you intend to delete, and only then run the `DELETE` (see Chapter 4 of the materials, "How to Run UPDATE/DELETE Safely")
