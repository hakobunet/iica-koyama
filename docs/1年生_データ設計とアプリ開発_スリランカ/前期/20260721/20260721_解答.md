# පාඩම 07 අභ්‍යාස｜පිළිතුරු උදාහරණ

> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [20260721_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260721/20260721_解答.md>) <!-- original-ja-link -->

`students` වගුවේ දත්ත（07 වන පාඩමේ සටහන් බලන්න）මත පදනම් වූ පිළිතුරු උදාහරණ මෙහි ඇත.

---

## ගැටලුව 1（SELECT මූලික කරුණු）

### පිළිතුර

```sql
-- ① name සහ class පමණක් ලබාගන්න
SELECT name, class FROM students;

-- ② name AS 氏名, score AS 点数 ලෙස ලබාගන්න
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ සියලු තීරු සහ සියලු පේළි ලබාගන්න
SELECT * FROM students;
```

---

## ගැටලුව 2（WHERE）

### පිළිතුර

```sql
-- ① class 'B' වන සිසුන්
SELECT * FROM students WHERE class = 'B';

-- ② age අවුරුදු 18 හෝ ඊට වැඩි, සහ score ලකුණු 80 හෝ ඊට වැඩි
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class 'A' හෝ 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name තුළ 「郎」 ඇතුළත්
SELECT * FROM students WHERE name LIKE '%郎%';
```

**ප්‍රතිඵලය（යොමුව සඳහා）:**
- ①: 山田次郎(91)、佐藤三郎(58)、吉田健太(88)
- ②: 田中太郎(85)、山田次郎(91)、渡辺一郎(95)、吉田健太(88)
- ③: 田中太郎・鈴木花子・伊藤美咲・山本麻衣（A）、渡辺一郎・加藤幸子・中村龍一（C）
- ④: 田中太郎・山田次郎・佐藤三郎・渡辺一郎（4 දෙනෙක්）

---

## ගැටලුව 3（ORDER BY / LIMIT）

### පිළිතුර

```sql
-- ① score අවරෝහණ පිළිවෙළට සියලු දෙනා
SELECT * FROM students ORDER BY score DESC;

-- ② ඉහළම 3 දෙනා පමණක්
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class ආරෝහණ, එකම class තුළ score අවරෝහණ
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**ප්‍රතිඵලය（යොමුව සඳහා）:**

②
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

③
```
[A] 田中太郎85, 伊藤美咲78, 鈴木花子72, 山本麻衣67
[B] 山田次郎91, 吉田健太88, 佐藤三郎58
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## ගැටලුව 4（සමූහ ශ්‍රිත / aggregate functions）

### පිළිතුර

```sql
-- ① සිසුන් ගණන
SELECT COUNT(*) FROM students;

-- ② එකතුව・සාමාන්‍යය・ඉහළම・අඩුම එකවර ලබාගන්න
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**ප්‍රතිඵලය（යොමුව සඳහා）:**
- ①: 10 දෙනෙක්
- ②: 合計点 752 ／ 平均点 75.2 ／ 最高点 95 ／ 最低点 45

---

## ගැටලුව 5（උසස්）

### පිළිතුර

```sql
-- ① ලකුණු 60 හෝ ඊට වැඩි සිසුන්ගේ එක් එක් class සඳහා සාමාන්‍ය ලකුණු සහ සිසුන් ගණන, සාමාන්‍ය ලකුණු වැඩිම අගයේ සිට අඩුම අගය දක්වා
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② class = 'A' හි වැඩිම ලකුණු ලබාගත් සිසුන් අතරින් එක් අයෙකු පමණක්
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**ප්‍රතිඵලය（යොමුව සඳහා）:**

①（ලකුණු 60 ට අඩු 佐藤三郎・加藤幸子 බැහැර කෙරේ）
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②
```
田中太郎 85点
```
