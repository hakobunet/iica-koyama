# පාඩම 07 අභ්‍යාස｜SQL මූලික කරුණු（SELECT / WHERE / ORDER BY）

> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [20260721_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260721/20260721_演習.md>) <!-- original-ja-link -->

## ගැටලුව 1（SELECT මූලික）: අවශ්‍ය column පමණක් ලබාගන්න

1. `name` සහ `class` පමණක් ලබාගන්න
2. `name` 「氏名」（සම්පූර්ණ නම）ලෙසත්, `score` 「点数」（ලකුණු）ලෙසත් අන්වර්ථ නාම (AS) භාවිතයෙන් ලබාගන්න
3. වගුවේ සියලු පේළි・සියලු column ලබාගන්න

```sql
-- ① name සහ class පමණක් ලබාගන්න

-- ② name AS 氏名, score AS 点数 ලෙස ලබාගන්න

-- ③ සියලු column・සියලු පේළි ලබාගන්න
```

---

## ගැටලුව 2（WHERE）: කොන්දේසි අනුව පෙරහන් කරන්න

1. `class` `'B'` වන සිසුන් ලබාගන්න
2. `age` අවුරුදු 18 හෝ ඊට වැඩි, සහ `score` ලකුණු 80 හෝ ඊට වැඩි සිසුන් ලබාගන්න
3. `class` `'A'` හෝ `'C'` වන සිසුන්, `IN` භාවිතයෙන් ලබාගන්න
4. `name` තුළ 「郎」 අක්ෂරය ඇතුළත් සිසුන්, `LIKE` භාවිතයෙන් ලබාගන්න

```sql
-- ①

-- ②

-- ③

-- ④
```

---

## ගැටලුව 3（ORDER BY / LIMIT）: පිළිවෙළට සැකසීම සහ ප්‍රමාණය සීමා කිරීම

1. `score` ඉහළ සිට පහළට（අවරෝහණ）සියලු දෙනා පිළිවෙළට සකසා ලබාගන්න
2. ඉහත ප්‍රතිඵලයෙන්, ඉහළම 3 දෙනා පමණක් ලබාගන්න（`LIMIT` භාවිත කරන්න）
3. `class` ආරෝහණ පිළිවෙළට, එකම `class` තුළ `score` අවරෝහණ පිළිවෙළට සකසා ලබාගන්න

```sql
-- ①

-- ②

-- ③
```

**② සඳහා අපේක්ෂිත ප්‍රතිඵලය（ඉහළම 3 දෙනා）:**
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

## ගැටලුව 4（සමූහ ශ්‍රිත / aggregate functions）: සමස්ත සංඛ්‍යාලේඛන සොයන්න

1. සිසුන් ගණන `COUNT(*)` මගින් සොයන්න
2. `score` හි එකතුව・සාමාන්‍යය・ඉහළම ලකුණ・අඩුම ලකුණ, පිළිවෙළින් 「合計点」（මුළු ලකුණු）「平均点」（සාමාන්‍ය ලකුණ）「最高点」（ඉහළම ලකුණ）「最低点」（අඩුම ලකුණ）යන අන්වර්ථ නාමවලින් එක් SQL එකකින් එකවර ලබාගන්න

```sql
-- ① සිසුන් ගණන ලබාගන්න

-- ② එකතුව・සාමාන්‍යය・ඉහළම・අඩුම එකවර ලබාගන්න
```

---

## ගැටලුව 5（උසස්）: WHERE + GROUP BY + ORDER BY එකට භාවිත කරන්න

1. `score` ලකුණු 60 හෝ ඊට වැඩි සිසුන් පමණක් සලකා, `class` අනුව සාමාන්‍ය ලකුණ（`AVG`）සහ සිසුන් ගණන（`COUNT`）සොයා, සාමාන්‍ය ලකුණ ඉහළ සිට පිළිවෙළට සකසන්න
2. `'A'` පන්තියේ සිසුන් අතරින්, වැඩිම ලකුණු ලබාගත් සිසුවා එක් අයෙකු පමණක් ලබාගන්න（`WHERE` + `ORDER BY` + `LIMIT` එකට භාවිත කරන්න）

```sql
-- ① ලකුණු 60 හෝ ඊට වැඩි සිසුන් සලකා, class අනුව සාමාන්‍ය ලකුණ・ගණන, සාමාන්‍ය ලකුණ ඉහළ සිට පිළිවෙළට

-- ② class = 'A' අතරින් වැඩිම ලකුණු ලබාගත් සිසුවා එක් අයෙකු පමණක්
```

**ඉඟිය:**
- ① `WHERE` → `GROUP BY` → `ORDER BY` පිළිවෙළට ලියන්න（ක්‍රියාත්මක වන පිළිවෙළ සඳහා පාඩම 07 හි සාරාංශය බලන්න）
- ② සඳහා `ORDER BY score DESC LIMIT 1` භාවිත කරන්න
