## අභ්‍යාසය 1: මූලික SELECT

### ①

```sql
SELECT * FROM orders;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** ඉහත ආරම්භක දත්ත පේළි 5 එලෙසම පෙන්වයි (`ordered_at` හි INSERT කළ මොහොතේ දිනය සහ වේලාව ඇතුළත් වේ).

### ②

```sql
SELECT * FROM products WHERE price >= 5000;
```

**ප්‍රතිඵලය (යොමුව සඳහා):**

| name | price |
|------|-------|
| ノートPC | 98000 |
| キーボード | 8500 |

マウス (යෙන් 3200) යෙන් 5000 ට අඩු නිසා ඇතුළත් නොවේ.

### ③

```sql
SELECT * FROM users ORDER BY id DESC;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** 山田次郎(id=3) → 鈴木花子(id=2) → 田中太郎(id=1) යන පිළිවෙළට පෙන්වයි.

### ④

```sql
SELECT MAX(price) AS 最高額, MIN(price) AS 最安値 FROM products;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** 最高額 (වැඩිම මිල) = 98000 (ノートPC), 最安値 (අඩුම මිල) = 3200 (マウス)

## අභ්‍යාසය 2: INSERT / UPDATE / DELETE

### ①

```sql
INSERT INTO users (name, email) VALUES ('中村健二', 'nakamura@example.com');
```

**ප්‍රතිඵලය (යොමුව සඳහා):** `id=4` ලෙස "中村健二" එකතු වේ.

### ②

```sql
INSERT INTO products (name, price) VALUES ('USBハブ', 2800);
```

**ප්‍රතිඵලය (යොමුව සඳහා):** `id=4` ලෙස "USBハブ" එකතු වේ.

### ③

```sql
-- මුලින්ම id පරීක්ෂා කරන්න
SELECT id FROM users WHERE name = '田中太郎';     -- → 1
SELECT id FROM products WHERE name = 'USBハブ';   -- → 4

-- පරීක්ෂා කළ id භාවිතා කර ඇණවුම එකතු කිරීම
INSERT INTO orders (user_id, product_id, quantity) VALUES (1, 4, 3);
```

**ප්‍රතිඵලය (යොමුව සඳහා):** `id=6` ඇණවුම ලෙස "田中太郎 විසින් USBハブ 3ක් ඇණවුම් කළ" දත්ත එකතු වේ.

### ④

```sql
-- කලින් පරීක්ෂා කිරීම
SELECT * FROM products WHERE name = 'ノートPC';

UPDATE products SET price = 95000 WHERE name = 'ノートPC';
```

**ප්‍රතිඵලය (යොමුව සඳහා):** ノートPC හි මිල යෙන් 98000 → යෙන් 95000 ලෙස වෙනස් වේ.

### ⑤

```sql
-- බාහිර යතුරු සීමාව ඇති නිසා, orders → users පිළිවෙළට මකා දමන්න
DELETE FROM orders
WHERE user_id = (SELECT id FROM users WHERE name = '中村健二');

DELETE FROM users WHERE name = '中村健二';
```

**ප්‍රතිඵලය (යොමුව සඳහා):** 中村健二 මෙම අභ්‍යාසය තුළ එක ඇණවුමක්වත් එකතු කර නැති නිසා, පළමු `DELETE` මගින් **කිසිදු පේළියක් මකා නොදැමේ** (කිසිවක් මැකෙන්නේ නැත ＝ නිවැරදි ප්‍රතිඵලයකි). දෙවන `DELETE` මගින් 中村健二(id=4) මැකී යයි.
මුලින්ම `users` මකා දැමීමට උත්සාහ කළොත් බාහිර යතුරු සීමාව නිසා දෝෂයක් ඇති වන බව මෙහි වැදගත් කරුණයි (මෙවර 中村健二 ගේ ඇණවුම් ඇත්තටම නැති නිසා බලපෑමක් නැත, නමුත් පිළිවෙළ පිළිපැදීමේ පුරුද්ද වැදගත්ය).

## අභ්‍යාසය 3: JOIN සහ සමුච්චය කිරීම (Aggregation)

### ①

```sql
SELECT
    users.name      AS ユーザー名,
    products.name   AS 商品名,
    orders.quantity AS 数量,
    products.price * orders.quantity AS 合計金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
ORDER BY orders.id;
```

**ප්‍රතිඵලය (යොමුව සඳහා):**

| ユーザー名 | 商品名 | 数量 | 合計金額 |
|---|---|---|---|
| 田中太郎 | ノートPC | 1 | 98000 |
| 田中太郎 | マウス | 2 | 6400 |
| 鈴木花子 | キーボード | 1 | 8500 |
| 山田次郎 | ノートPC | 1 | 98000 |
| 鈴木花子 | ノートPC | 1 | 98000 |

### ②

```sql
SELECT
    products.name   AS 商品名,
    orders.quantity AS 数量,
    products.price * orders.quantity AS 金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
WHERE users.name = '田中太郎';
```

**ප්‍රතිඵලය (යොමුව සඳහා):**

| 商品名 | 数量 | 金額 |
|---|---|---|
| ノートPC | 1 | 98000 |
| マウス | 2 | 6400 |

### ③

```sql
SELECT
    products.name AS 商品名,
    SUM(orders.quantity) AS 販売数量,
    SUM(products.price * orders.quantity) AS 売上合計
FROM orders
INNER JOIN products ON orders.product_id = products.id
GROUP BY products.id, products.name
ORDER BY 売上合計 DESC;
```

**ප්‍රතිඵලය (යොමුව සඳහා):**

| 商品名 | 販売数量 | 売上合計 |
|---|---|---|
| ノートPC | 3 | 294000 |
| キーボード | 1 | 8500 |
| マウス | 2 | 6400 |

### ④

```sql
SELECT users.name, users.email
FROM users
LEFT JOIN orders ON users.id = orders.user_id
WHERE orders.id IS NULL;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** ආරම්භක දත්තවල 田中太郎, 鈴木花子, 山田次郎 යන සියලු දෙනාම අවම වශයෙන් එක් වරක්වත් ඇණවුම් කර ඇති නිසා, **ප්‍රතිඵලය පේළි 0යි**.

## අභ්‍යාසය 4: ව්‍යවහාරික ප්‍රශ්න

### ①

```sql
SELECT
    users.name AS ユーザー名,
    AVG(products.price * orders.quantity) AS 平均購入金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
GROUP BY users.id, users.name
ORDER BY 平均購入金額 DESC
LIMIT 1;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** එක් ඇණවුමක සාමාන්‍ය මිලදී ගැනීමේ මුදල: 田中太郎 = (98000+6400)/2 = යෙන් 52200, 鈴木花子 = (8500+98000)/2 = යෙන් 53250, 山田次郎 = යෙන් 98000 (එක් ඇණවුමක් පමණි). එබැවින් **山田次郎ගේ සාමාන්‍ය මිලදී ගැනීමේ මුදල (යෙන් 98000)** වැඩිම අගය වේ.

### ②

```sql
SELECT
    users.name AS ユーザー名,
    MAX(orders.ordered_at) AS 最新注文日時
FROM orders
INNER JOIN users ON orders.user_id = users.id
GROUP BY users.id, users.name;
```

**ප්‍රතිඵලය (යොමුව සඳහා):** ආරම්භක දත්ත එක් `INSERT` ප්‍රකාශයකින් එකවර ලියාපදිංචි කළ නිසා, තිදෙනාගේම `ordered_at` අගය එම ප්‍රකාශය ක්‍රියාත්මක කළ මොහොතේ දිනය හා වේලාවට සමාන වේ. වෙනස් දිනවල ඇණවුම් එකතු කළොත්, පරිශීලකයා අනුව වෙනස් වන "නවතම ඇණවුම් දිනය සහ වේලාව" දැකිය හැකි වේ.

### ③

```sql
SELECT
    users.name  AS ユーザー名,
    users.email AS メール
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
GROUP BY users.id, users.name, users.email
HAVING SUM(products.price * orders.quantity) >= 100000;
```

**ප්‍රතිඵලය (යොමුව සඳහා):**

| ユーザー名 | メール |
|---|---|
