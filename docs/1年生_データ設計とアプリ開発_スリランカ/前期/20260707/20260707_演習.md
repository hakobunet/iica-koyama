## Part 1｜array・associative array

### ගැටලුව 1-1: array එකක දත්ත ගණනය කරන්න

විභාග ලකුණු ඇතුළත් array එකෙන්, එකතුව・සාමාන්‍යය・ඉහළම ලකුණ・අඩුම ලකුණ සහ 「සමත් වූ සංඛ්‍යාව（ලකුණු 70 හෝ ඊට වැඩි）」 සොයන්න.

```php
<?php
$scores = [85, 42, 91, 67, 78, 55, 93, 70, 61, 88];

// ① මුළු ලකුණු ප්‍රතිදානය කරන්න

// ② සාමාන්‍ය ලකුණ ප්‍රතිදානය කරන්න（එක් දශමස්ථානයකට）
//    ඉඟිය: number_format($avg, 1)

// ③ ඉහළම ලකුණ සහ අඩුම ලකුණ ප්‍රතිදානය කරන්න

// ④ ලකුණු 70 හෝ ඊට වැඩි සමත් වූ සංඛ්‍යාව ප්‍රතිදානය කරන්න
//    ඉඟිය: array_filter + count
?>
```

### ගැටලුව 1-2: associative array වලින් සමන්විත array එකක් හසුරුවන්න

පහත සිසුන්ගේ දත්තවලින් කොන්දේසියට ගැළපෙන සිසුන් තෝරා පෙන්වන්න.

```php
<?php
$students = [
    ["id" => 1, "name" => "田中太郎", "class" => "A", "score" => 85],
    ["id" => 2, "name" => "鈴木花子", "class" => "B", "score" => 62],
    ["id" => 3, "name" => "山田次郎", "class" => "A", "score" => 91],
    ["id" => 4, "name" => "佐藤三郎", "class" => "B", "score" => 47],
    ["id" => 5, "name" => "伊藤美咲", "class" => "A", "score" => 78],
];

// ① සියලු සිසුන් 「ID:1 田中太郎 (Aクラス) 85点」 ආකාරයෙන් ප්‍රතිදානය කරන්න

// ② A පන්තියේ සිසුන් පමණක් ප්‍රතිදානය කරන්න

// ③ ලකුණු 80 හෝ ඊට වැඩි සිසුන් පමණක් ප්‍රතිදානය කරන්න
?>
```

## Part 2｜කොන්දේසි අනුව ශාඛාකරණය・ශ්‍රිත (function)

### ගැටලුව 2-1: ශ්‍රේණි ඇගයීමේ ශ්‍රිතයක් සාදන්න

ලකුණ ලබාගෙන ශ්‍රේණිය string එකක් ලෙස ආපසු දෙන `getGrade()` ශ්‍රිතය සාදන්න.

| ලකුණ | ශ්‍රේණිය |
| --- | --- |
| 90 හෝ ඊට වැඩි | S |
| 80 හෝ ඊට වැඩි | A |
| 70 හෝ ඊට වැඩි | B |
| 60 හෝ ඊට වැඩි | C |
| 60 ට අඩු | D |

```php
<?php
function getGrade(int $score): string {
    // මෙතන if/elseif ලියන්න

}

// ක්‍රියාකාරිත්වය පරීක්ෂා කිරීම
```

### ගැටලුව 2-2: match expression මගින් වයස් කාණ්ඩය තීරණය කරන්න

වයස ලබාගෙන කාණ්ඩය ආපසු දෙන `getAgeGroup()` ශ්‍රිතය `match` expression එකක් භාවිතයෙන් සාදන්න.

| කොන්දේසිය | කාණ්ඩය |
| --- | --- |
| අවුරුදු 12 ට අඩු | 子ども（ළමයා） |
| අවුරුදු 18 ට අඩු | 中高生（ද්විතීයික පාසල් සිසුවා） |
| අවුරුදු 65 ට අඩු | 大人（වැඩිහිටියා） |
| අවුරුදු 65 හෝ ඊට වැඩි | シニア（ජ්‍යෙෂ්ඨ පුරවැසියා） |

```php
<?php
function getAgeGroup(int $age): string {
    // match(true) සමඟ සංයෝජනය කර ලියන්න
```

## Part 3｜පෝරම (form) සහ POST

### ගැටලුව 3-1: විමසීම් පෝරමයක් සාදන්න

`contact.php` එක් ගොනුවකින් සාදන්න.

**පිරිවිතර（specification）:**
- ඇතුළත් කරන අයිතම: නම・විද්‍යුත් තැපැල් ලිපිනය・පණිවිඩය
- යැවූ පසු 「〇〇さんからのお問い合わせを受け付けました」（〇〇 ගෙන් ලැබුණු විමසීම භාර ගත්තා）ලෙස පෙන්වන්න
- XSS ආරක්ෂාව සඳහා `htmlspecialchars()` අනිවාර්යයෙන්ම භාවිත කරන්න

```php
<?php
// ▼ contact.php හි ලියමු

$name    = "";
$email   = "";
$message = "";
$sent    = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // ① දත්ත ලබාගන්න（?? "" මගින් null වළක්වන්න）

    // ② htmlspecialchars හරහා යවන්න

    $sent = true;
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>問い合わせ</title></head>
<body>
<?php if ($sent): ?>
  <!-- යැවීම සම්පූර්ණ වූ පණිවිඩය -->
<?php else: ?>
  <!-- පෝරමය -->
<?php endif; ?>
</body>
</html>
```

### ගැටලුව 3-2: වලංගුකරණය (validation) සහිත පෝරමයක් සාදන්න

`register.php` සාදා, පහත වලංගුකරණය ක්‍රියාත්මක කරන්න.

**වලංගුකරණ කොන්දේසි:**
- නම: අනිවාර්යයි・අක්ෂර 50 ක් ඇතුළත
- වයස: අනිවාර්යයි・0〜120 අතර පූර්ණ සංඛ්‍යාවක්
- දෝෂ ඇති විට රතු අකුරින් ලැයිස්තුවක් ලෙස පෙන්වා, ඇතුළත් කළ අගයන් රඳවා තබන්න

```php
<?php
$errors = [];
$name   = "";
$age    = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    $age  = trim($_POST["age"]  ?? "");

    // ① නමේ වලංගුකරණය

    // ② වයසේ වලංගුකරණය

    // ③ දෝෂ නැත්නම් සාර්ථක පණිවිඩය
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>登録</title></head>
<body>
  <!-- ④ දෝෂ ඇත්නම් රතු අකුරින් පෙන්වන්න -->

  <form method="post" action="">
    <label>名前：<input type="text" name="name" value="<?= htmlspecialchars($name) ?>"></label><br>
    <label>年齢：<input type="number" name="age" value="<?= htmlspecialchars($age) ?>"></label><br>
    <button type="submit">登録</button>
  </form>
</body>
</html>
```
