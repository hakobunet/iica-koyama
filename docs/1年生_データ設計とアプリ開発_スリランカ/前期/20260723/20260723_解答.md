# පාඩම 08 අභ්‍යාසය｜ආදර්ශ පිළිතුරු

> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [20260723_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260723/20260723_解答.md>) <!-- original-ja-link -->

මෙය `students` වගුවේ ආරම්භක දත්ත (පාඩම 07 හි ඉගෙනුම් ද්‍රව්‍ය බලන්න) පදනම් කරගත් ආදර්ශ පිළිතුරු එකතුවකි.
වෙනත් ලෙස සඳහන් කර නොමැති නම්, සෑම ප්‍රශ්නයක්ම "ආරම්භක දත්තවල සිට කරන මෙහෙයුමක්" ලෙස වෙන වෙනම සලකන්න.

## ප්‍රශ්නය 1 (INSERT)

### පිළිතුර

```sql
-- ① 新入生F සඳහා පේළියක් එක් කිරීම
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② 新入生G සහ H එක් INSERT ප්‍රකාශයකින් එකතු කිරීම
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**ප්‍රතිඵලය (යොමුව සඳහා):**
- ①: `id=11` ලෙස "新入生F" එකතු වේ (`id` AUTO_INCREMENT නිසා එය සඳහන් කිරීම අවශ්‍ය නැත)
- ②: `id=12` "新入生G" සහ `id=13` "新入生H" එකවර එකතු වේ

## ප්‍රශ්නය 2 (UPDATE)

### පිළිතුර

```sql
-- ① id=3 සිසුවාගේ class අගය 'S' ලෙස යාවත්කාලීන කිරීම
UPDATE students SET class = 'S' WHERE id = 3;

-- ② class 'B' වන සියලුම සිසුන්ගේ score වලට +10
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**ප්‍රතිඵලය (යොමුව සඳහා):**
- ①: 山田次郎 (id=3) ගේ `class` අගය `B` → `S` ලෙස වෙනස් වේ
- ②: class='B' වන සිසුන් 3 දෙනාටම මෙය අදාළ වේ
  - 山田次郎: 91 → 101
  - 佐藤三郎: 58 → 68
  - 吉田健太: 88 → 98

③ හි පැහැදිලි කිරීම:
> `WHERE` දැමීමට අමතක වී `UPDATE students SET score = 0;` ක්‍රියාත්මක කළොත්, `students` වගුවේ **පේළි 10ම** ඉලක්ක වී, කිසිදු ව්‍යතිරේකයකින් තොරව සියලු දෙනාගේ `score` 0 බවට පත් වේ. `UPDATE`/`DELETE` ක්‍රියාත්මක කිරීමට පෙර අනිවාර්යයෙන්ම `WHERE` පරීක්ෂා කළ යුතුය.

## ප්‍රශ්නය 3 (DELETE)

### පිළිතුර

```sql
-- ① id=8 සිසුවා මකා දැමීම
DELETE FROM students WHERE id = 8;

-- ② score ලකුණු 40 ට අඩු සියලුම සිසුන් මකා දැමීම
DELETE FROM students WHERE score < 40;

-- ③ ② ක්‍රියාත්මක කිරීමට පෙර, ඊට අදාළ පේළි SELECT මගින් පරීක්ෂා කිරීම
SELECT * FROM students WHERE score < 40;
```

**ප්‍රතිඵලය (යොමුව සඳහා):**
- ①: 吉田健太 (id=8) මකා දැමේ
- ②: ආරම්භක දත්තවල අඩුම ලකුණු ගණන 45 (加藤幸子) නිසා, `score < 40` ට ගැළපෙන සිසුන් **0** කි. එනම් මෙම `DELETE` ප්‍රකාශයෙන් කිසිවක් මකා නොදැමේ ("අදාළ පේළි 0" යන්නත් නිවැරදි ප්‍රතිඵලයකි)
- ③: ② හි `DELETE` ප්‍රකාශයට පෙර අනිවාර්යයෙන්ම මෙය ක්‍රියාත්මක කර, මකා දැමීමට නියමිත පේළි අපේක්ෂා කළ ඒවාදැයි පරීක්ෂා කළ පසු `DELETE` ක්‍රියාත්මක කරන්න (ඉගෙනුම් ද්‍රව්‍යයේ 4 වන පරිච්ඡේදයේ "ආරක්ෂිතව UPDATE/DELETE කරන ආකාරය" බලන්න)
