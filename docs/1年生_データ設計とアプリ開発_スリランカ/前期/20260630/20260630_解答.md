## ගැටලුව 1 පිළිතුර

```php
<?php
$name  = "田中太郎";
$age   = 20;
$hobby = "プログラミング";

echo "名前：{$name}<br>";
echo "年齢：{$age}歳<br>";
echo "趣味：{$hobby}<br>";
?>
```

## ගැටලුව 2 පිළිතුර

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

echo "<ul>";
foreach ($fruits as $fruit) {
    echo "<li>{$fruit}</li>";
}
echo "</ul>";
?>
```

## ගැටලුව 3 පිළිතුර

```php
<?php
$total = 0;

for ($i = 1; $i <= 10; $i++) {
    $total += $i;
}

echo "合計: " . $total;  // → 合計: 55
?>
```

## ගැටලුව 4 පිළිතුර（උසස්）

```php
<?php
for ($dan = 2; $dan <= 5; $dan++) {
    for ($i = 1; $i <= 9; $i++) {
        echo "{$dan}×{$i}=" . ($dan * $i) . "  ";
    }
    echo "<br>";
}
?>
```
