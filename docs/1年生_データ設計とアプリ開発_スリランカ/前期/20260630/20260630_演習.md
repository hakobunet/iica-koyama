> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [20260630_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260630/20260630_演習.md>) <!-- original-ja-link -->

`src/index.php` සාදා, එක් එක් ගැටලුවේ කේතය ලියා `php -S localhost:8000` මගින් ක්‍රියාකාරිත්වය පරීක්ෂා කරමු.

## ගැටලුව 1: ඔබ ගැන හැඳින්වීමක් පෙන්වන්න

`$name`・`$age`・`$hobby` යන විචල්‍ය (variable) නිර්වචනය කර, පහත ආකාරයට පෙන්වන PHP ගොනුවක් ලියන්න.

**අපේක්ෂිත ප්‍රතිදාන උදාහරණය（බ්‍රවුසරයේ පෙන්වන ආකාරය）:**
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

කොන්දේසි:
- විචල්‍ය අනිවාර්යයෙන්ම `$` වලින් ආරම්භ කරන්න
- විචල්‍යය string එක තුළට ඇතුළත් කර, `"..."` ආකාරයෙන් ප්‍රතිදානය කරන්න

```php
<?php
// මෙතන ලියමු


?>
```

---

## ගැටලුව 2: array එකක් HTML ලැයිස්තුවක් ලෙස පෙන්වන්න

`$fruits = ["りんご", "みかん", "ぶどう", "バナナ"]` `foreach` මගින් loop කර, `<ul>` / `<li>` ටැග් භාවිතයෙන් HTML ලෙස පෙන්වන්න.

**අපේක්ෂිත ප්‍රතිදානය（බ්‍රවුසරයේ පෙන්වන ආකාරය）:**
```
• りんご
• みかん
• ぶどう
• バナナ
```

කොන්දේසි:
- `foreach` භාවිත කළ යුතුය
- HTML හි `<ul>` සහ `<li>` ටැග් echo මගින් ප්‍රතිදානය කළ යුතුය

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// මෙතන ලියමු


?>
```

## ගැටලුව 3: 1 සිට 10 දක්වා එකතුව ගණනය කරන්න

`for` loop එකක් භාවිතයෙන් 1 සිට 10 දක්වා සියලු පූර්ණ සංඛ්‍යාවල එකතුව ගණනය කර ප්‍රතිදානය කරන්න.

**අපේක්ෂිත ප්‍රතිදානය:**
```
合計: 55
```

කොන්දේසි:
- `for` loop එකක් භාවිත කළ යුතුය
- එකතුව ගබඩා කරන `$total` විචල්‍යය භාවිත කළ යුතුය

```php
<?php
$total = 0;

// මෙතන ලියමු


echo "合計: " . $total;
?>
```

## ගැටලුව 4（උසස්）: ගුණන වගුවක් සාදන්න

`for` loop එකක් තුළ තවත් `for` loop එකක් (nested) භාවිත කර, 2 සිට 5 දක්වා ගුණන වගු පෙන්වන්න.

**අපේක්ෂිත ප්‍රතිදානය（කොටසක්）:**
```
2×1=2  2×2=4  2×3=6 ...
3×1=3  3×2=6  3×3=9 ...
```

```php
<?php
// මෙතන ලියමු


?>
```
