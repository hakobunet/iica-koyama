# වැදගත් command ලැයිස්තුව

> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [重要コマンド一覧.md](<../../1年生_データ設計とアプリ開発/後期/重要コマンド一覧.md>) <!-- original-ja-link -->

> Command ටයිප් කරන්නේ **VS Code terminal එකේ**.
> Docker Desktop ආරම්භ කළාට පස්සේ භාවිත කරමු.

---

## ආරම්භ කිරීම සහ නැවැත්වීම

### ආරම්භ කිරීම (mysql → laravel පිළිවෙළට)

```powershell
docker compose up -d
```

### නැවැත්වීම (laravel → mysql පිළිවෙළට)

```powershell
docker compose down
```

ආරම්භ කළාට පස්සේ browser එකෙන් විවෘත කරන්න.

| URL | බලන්න පුළුවන් දේ |
|-----|------------|
| http://localhost:8000 | Laravel (අපි හදන app එක) |
| http://localhost:8080 | phpMyAdmin (database) |

---

## File හැදීම

laravel folder එකේ ටයිප් කරන්න.

### Migration file එකක් හැදීම

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### Model එකක් හැදීම

```powershell
docker compose exec laravel php artisan make:model Todo
```

### Controller එකක් හැදීම

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## Database එකේ වැඩ කිරීම

laravel folder එකේ ටයිප් කරන්න.

### Table හැදීම

```powershell
docker compose exec laravel php artisan migrate
```
