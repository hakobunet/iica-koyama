# कक्षा 10 अभ्यास｜उत्तरको नमुना

> 🇯🇵 मूल प्रति (जापानी भाषामा): [20260728_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260728/20260728_解答.md>) <!-- original-ja-link -->

`school_db` का users / products / orders को सुरुको डाटा (कक्षा 09 को सामग्री हेर्नुहोस्) को आधारमा बनाइएको उत्तरको नमुना हो।
अभ्यास 1, अभ्यास 3 र अभ्यास 4 लाई, अरू केही नभनिएसम्म "अभ्यास 2 चलाउनुअघिको सुरुको डाटा" को आधारमा सोच्नुहोस्
(अभ्यास 2 लाई ①→⑤ को क्रममा चलाइने, लगातारको काम मानिन्छ)।

```
users टेबल (सुरुको डाटा)
id │ name     │ email
───┼──────────┼────────────────────
 1 │ 田中太郎 │ tanaka@example.com
 2 │ 鈴木花子 │ suzuki@example.com
 3 │ 山田次郎 │ yamada@example.com

products टेबल (सुरुको डाटा)
id │ name       │ price
───┼────────────┼───────
 1 │ ノートPC   │ 98000
 2 │ マウス     │  3200
 3 │ キーボード │  8500

orders टेबल (सुरुको डाटा)
id │ user_id │ product_id │ quantity
───┼─────────┼────────────┼─────────
 1 │    1    │     1      │    1     -- 田中太郎: ノートPC ×1
 2 │    1    │     2      │    2     -- 田中太郎: マウス ×2
 3 │    2    │     3      │    1     -- 鈴木花子: キーボード ×1
 4 │    3    │     1      │    1     -- 山田次郎: ノートPC ×1
 5 │    2    │     1      │    1     -- 鈴木花子: ノートPC ×1
```

---

## अभ्यास 1: आधारभूत SELECT

### ①

```sql
SELECT * FROM orders;
```

**नतिजा (सन्दर्भका लागि):** माथिको सुरुको डाटा 5 वटा जस्ताको तस्तै देखिन्छ (`ordered_at` मा INSERT गरेको बेलाको मिति र समय राखिन्छ)।

### ②

```sql
SELECT * FROM products WHERE price >= 5000;
```

**नतिजा (सन्दर्भका लागि):**

| name | price |
|------|-------|
| ノートPC | 98000 |
| キーボード | 8500 |

マウス (3200 येन) 5000 येनभन्दा कम भएकाले पर्दैन।

### ③

```sql
SELECT * FROM users ORDER BY id DESC;
```

**नतिजा (सन्दर्भका लागि):** 山田次郎(id=3) → 鈴木花子(id=2) → 田中太郎(id=1) को क्रममा देखिन्छ।

### ④

```sql
SELECT MAX(price) AS 最高額, MIN(price) AS 最安値 FROM products;
```

**नतिजा (सन्दर्भका लागि):** 最高額 (सबैभन्दा महँगो) = 98000 (ノートPC), 最安値 (सबैभन्दा सस्तो) = 3200 (マウス)

## अभ्यास 2: INSERT / UPDATE / DELETE

### ①

```sql
INSERT INTO users (name, email) VALUES ('中村健二', 'nakamura@example.com');
```

**नतिजा (सन्दर्भका लागि):** `id=4` को रूपमा "中村健二" थपिन्छ।

### ②

```sql
INSERT INTO products (name, price) VALUES ('USBハブ', 2800);
```

**नतिजा (सन्दर्भका लागि):** `id=4` को रूपमा "USBハブ" थपिन्छ।

### ③

```sql
-- पहिले id जाँच्ने
SELECT id FROM users WHERE name = '田中太郎';     -- → 1
SELECT id FROM products WHERE name = 'USBハブ';   -- → 4

-- जाँचेको id प्रयोग गरेर अर्डर थप्ने
INSERT INTO orders (user_id, product_id, quantity) VALUES (1, 4, 3);
```

**नतिजा (सन्दर्भका लागि):** 田中太郎 ले 3 वटा USBハブ अर्डर गरेको डाटा `id=6` भएको अर्डरका रूपमा थपिन्छ।

### ④

```sql
-- पहिल्यै जाँच्ने
SELECT * FROM products WHERE name = 'ノートPC';

UPDATE products SET price = 95000 WHERE name = 'ノートPC';
```

**नतिजा (सन्दर्भका लागि):** ノートPC को मूल्य 98000 येन → 95000 येनमा परिवर्तन हुन्छ।

### ⑤

```sql
-- फरेन की constraint भएकाले, orders → users को क्रममा मेटाउने
DELETE FROM orders
WHERE user_id = (SELECT id FROM users WHERE name = '中村健二');

DELETE FROM users WHERE name = '中村健二';
```

**नतिजा (सन्दर्भका लागि):** यो अभ्यासमा 中村健二 को एउटा पनि अर्डर थपिएको छैन, त्यसैले पहिलो `DELETE` को **लक्षित row सङ्ख्या 0** हुन्छ (केही पनि मेटिँदैन = सही नतिजा)। दोस्रो `DELETE` ले 中村健二(id=4) लाई मेटाउँछ।
पहिले `users` मेटाउन खोज्यो भने फरेन की constraint ले त्रुटि दिन्छ भन्ने कुरा महत्त्वपूर्ण छ (यस पटक 中村健二 को अर्डर वास्तवमा नभएकाले असर पर्दैन, तर क्रम पालना गर्ने बानी महत्त्वपूर्ण हुन्छ)।

## अभ्यास 3: JOIN र गणना (aggregation)

### ①

```sql
SELECT
    users.name      AS ユーザー名,
    products.name   AS 商品名,
    orders.quantity AS 数量,
    products.price * orders.quantity AS 合計金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
ORDER BY orders.id;
```

**नतिजा (सन्दर्भका लागि):**

| ユーザー名 | 商品名 | 数量 | 合計金額 |
|---|---|---|---|
| 田中太郎 | ノートPC | 1 | 98000 |
| 田中太郎 | マウス | 2 | 6400 |
| 鈴木花子 | キーボード | 1 | 8500 |
| 山田次郎 | ノートPC | 1 | 98000 |
| 鈴木花子 | ノートPC | 1 | 98000 |

### ②

```sql
SELECT
    products.name   AS 商品名,
    orders.quantity AS 数量,
    products.price * orders.quantity AS 金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
WHERE users.name = '田中太郎';
```

**नतिजा (सन्दर्भका लागि):**

| 商品名 | 数量 | 金額 |
|---|---|---|
| ノートPC | 1 | 98000 |
| マウス | 2 | 6400 |

### ③

```sql
SELECT
    products.name AS 商品名,
    SUM(orders.quantity) AS 販売数量,
    SUM(products.price * orders.quantity) AS 売上合計
FROM orders
INNER JOIN products ON orders.product_id = products.id
GROUP BY products.id, products.name
ORDER BY 売上合計 DESC;
```

**नतिजा (सन्दर्भका लागि):**

| 商品名 | 販売数量 | 売上合計 |
|---|---|---|
| ノートPC | 3 | 294000 |
| キーボード | 1 | 8500 |
| マウス | 2 | 6400 |

### ④

```sql
SELECT users.name, users.email
FROM users
LEFT JOIN orders ON users.id = orders.user_id
WHERE orders.id IS NULL;
```

**नतिजा (सन्दर्भका लागि):** सुरुको डाटामा 田中太郎, 鈴木花子, 山田次郎 सबैले कम्तीमा 1 पटक अर्डर गरेकाले, **नतिजा 0 वटा** हुन्छ।
(अभ्यास 2 मा थपिएका 中村健二 लाई यस बेलासम्म नमेटाइएको भए, अर्डर नगरेका 中村健二 को एउटा मात्र row भेटिन्छ। "अर्डर नगरेका user छैनन् = 0 row आउनु पनि सही नतिजा हो" भन्ने कुरा यस प्रश्नको मुख्य बुँदा हो।)

## अभ्यास 4: अनुप्रयोगमूलक प्रश्न

### ①

```sql
SELECT
    users.name AS ユーザー名,
    AVG(products.price * orders.quantity) AS 平均購入金額
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
GROUP BY users.id, users.name
ORDER BY 平均購入金額 DESC
LIMIT 1;
```

**नतिजा (सन्दर्भका लागि):** प्रति अर्डर औसत खरिद रकम: 田中太郎 = (98000+6400)/2 = 52200 येन, 鈴木花子 = (8500+98000)/2 = 53250 येन, 山田次郎 = 98000 येन (अर्डर 1 वटा मात्र)। त्यसैले **山田次郎 (98000 येन)** सबैभन्दा बढी हो।

### ②

```sql
SELECT
    users.name AS ユーザー名,
    MAX(orders.ordered_at) AS 最新注文日時
FROM orders
INNER JOIN users ON orders.user_id = users.id
GROUP BY users.id, users.name;
```

**नतिजा (सन्दर्भका लागि):** सुरुको डाटा एउटै `INSERT` statement ले एकै पटक दर्ता गरिएकाले, तीनै जनाको `ordered_at` मा statement चलाइएको क्षणको एउटै मिति र समय हुन्छ। फरक-फरक दिनमा अर्डर थप्यो भने, user अनुसार फरक "सबैभन्दा पछिल्लो अर्डरको मिति र समय" देख्न सकिन्छ।

### ③

```sql
SELECT
    users.name  AS ユーザー名,
    users.email AS メール
FROM orders
INNER JOIN users    ON orders.user_id    = users.id
INNER JOIN products ON orders.product_id = products.id
GROUP BY users.id, users.name, users.email
HAVING SUM(products.price * orders.quantity) >= 100000;
```

**नतिजा (सन्दर्भका लागि):**

| ユーザー名 | メール |
|---|---|
| 田中太郎 | tanaka@example.com |
| 鈴木花子 | suzuki@example.com |

田中太郎 को कुल खरिद रकम 104400 येन र 鈴木花子 को 106500 येन भएकाले दुवै 100000 येन वा सोभन्दा बढी छन्। 山田次郎 98000 येन भएकाले पर्दैन।
