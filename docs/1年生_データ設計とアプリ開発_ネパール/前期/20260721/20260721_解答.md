# कक्षा 07 अभ्यास｜उत्तरको उदाहरण

> 🇯🇵 मूल प्रति (जापानी भाषामा): [20260721_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260721/20260721_解答.md>) <!-- original-ja-link -->

`students` टेबलको डाटा (कक्षा 07 को सामग्री हेर्नुहोस्) का आधारमा तयार पारिएका उत्तरका उदाहरणहरू तल दिइएका छन्।

---

## प्रश्न 1 (SELECT का आधारभूत कुराहरू)

### उत्तर

```sql
-- ① name र class मात्र निकाल्ने
SELECT name, class FROM students;

-- ② name AS 氏名, score AS 点数 गरेर निकाल्ने
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ सबै कोलम र सबै रो निकाल्ने
SELECT * FROM students;
```

---

## प्रश्न 2 (WHERE)

### उत्तर

```sql
-- ① class 'B' भएका विद्यार्थी
SELECT * FROM students WHERE class = 'B';

-- ② age 18 वर्ष वा बढी, र score 80 अङ्क वा बढी
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class 'A' वा 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name मा "郎" भएका
SELECT * FROM students WHERE name LIKE '%郎%';
```

**नतिजा (सन्दर्भका लागि):**
- ①: 山田次郎(91)、佐藤三郎(58)、吉田健太(88)
- ②: 田中太郎(85)、山田次郎(91)、渡辺一郎(95)、吉田健太(88)
- ③: 田中太郎・鈴木花子・伊藤美咲・山本麻衣 (A)、渡辺一郎・加藤幸子・中村龍一 (C)
- ④: 田中太郎・山田次郎・佐藤三郎・渡辺一郎 (4 जना)

---

## प्रश्न 3 (ORDER BY / LIMIT)

### उत्तर

```sql
-- ① score को घट्दो क्रममा सबै जना
SELECT * FROM students ORDER BY score DESC;

-- ② शीर्ष 3 जना मात्र
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class बढ्दो क्रम, एउटै class भित्र score घट्दो क्रम
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**नतिजा (सन्दर्भका लागि):**

②
```

山田次郎 91点
吉田健太 88点
```

③
```

[B] 山田次郎91, 吉田健太88, 佐藤三郎58
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## प्रश्न 4 (एग्रिगेट फङ्सन)

### उत्तर

```sql
-- ① विद्यार्थीहरूको सङ्ख्या
SELECT COUNT(*) FROM students;

-- ② जम्मा, औसत, सबैभन्दा बढी र सबैभन्दा कम अङ्क एकैपटक निकाल्ने
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**नतिजा (सन्दर्भका लागि):**
- ①: 10 जना
- ②: 合計点 752 ／ 平均点 75.2 ／ 最高点 95 ／ 最低点 45

---

## प्रश्न 5 (उन्नत)

### उत्तर

```sql
-- ① 60 अङ्क वा बढी ल्याएका विद्यार्थीहरूको class अनुसार औसत अङ्क र सङ्ख्या, औसत अङ्कको घट्दो क्रममा
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② class = 'A' भित्र सबैभन्दा बढी अङ्क ल्याउने एक जना मात्र
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**नतिजा (सन्दर्भका लागि):**

① (60 अङ्कभन्दा कम ल्याउने 佐藤三郎・加藤幸子 हटाइन्छन्)
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②
```
田中太郎 85点
```
