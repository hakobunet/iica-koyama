# कक्षा 08 अभ्यास｜उत्तरको नमुना

> 🇯🇵 मूल प्रति (जापानी भाषामा): [20260723_解答.md](<../../../1年生_データ設計とアプリ開発/前期/20260723/20260723_解答.md>) <!-- original-ja-link -->

`students` टेबलको सुरुको डाटा (कक्षा 07 को सामग्री हेर्नुहोस्) को आधारमा बनाइएको उत्तरको नमुना हो।
अन्यथा उल्लेख नभएसम्म, हरेक प्रश्नमा सुरुको डाटाबाट काम गर्ने गरी छुट्टाछुट्टै विचार गर्नुहोस्।

```
सुरुको डाटा (10 वटा)
 id │ name     │ age │ class │ score
────┼──────────┼─────┼───────┼──────
  1 │ 田中太郎 │ 18  │ A     │ 85
  2 │ 鈴木花子 │ 19  │ A     │ 72
  3 │ 山田次郎 │ 18  │ B     │ 91
  4 │ 佐藤三郎 │ 20  │ B     │ 58
  5 │ 伊藤美咲 │ 18  │ A     │ 78
  6 │ 渡辺一郎 │ 19  │ C     │ 95
  7 │ 加藤幸子 │ 18  │ C     │ 45
  8 │ 吉田健太 │ 20  │ B     │ 88
  9 │ 山本麻衣 │ 19  │ A     │ 67
 10 │ 中村龍一 │ 18  │ C     │ 73
```

---

## प्रश्न 1 (INSERT)

### उत्तर

```sql
-- ① 新入生F लाई एउटा row को रूपमा थप्ने
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES ('新入生F', 19, 'B', 70, '2024-04-01');

-- ② 新入生G र H लाई एउटै INSERT statement बाट थप्ने
INSERT INTO students (name, age, class, score, enrolled_at)
VALUES
    ('新入生G', 18, 'A', 82, '2024-04-01'),
    ('新入生H', 20, 'C', 55, '2024-04-01');
```

**नतिजा (सन्दर्भका लागि):**
- ①: "新入生F" लाई `id=11` दिएर थपिन्छ (`id` AUTO_INCREMENT भएकाले तोक्नु पर्दैन)
- ②: `id=12` "新入生G" र `id=13` "新入生H" एकै पटक थपिन्छन्

---

## प्रश्न 2 (UPDATE)

### उत्तर

```sql
-- ① id=3 भएको विद्यार्थीको class लाई 'S' मा अपडेट गर्ने
UPDATE students SET class = 'S' WHERE id = 3;

-- ② class 'B' भएका सबै विद्यार्थीको score मा +10
UPDATE students SET score = score + 10 WHERE class = 'B';
```

**नतिजा (सन्दर्भका लागि):**
- ①: 山田次郎 (id=3) को `class` `B` → `S` मा परिवर्तन हुन्छ
- ②: class='B' भएका 3 जना लक्षित हुन्छन्
  - 山田次郎: 91 → 101
  - 佐藤三郎: 58 → 68
  - 吉田健太: 88 → 98

③ को व्याख्या:
> `WHERE` लेख्न बिर्सेर `UPDATE students SET score = 0;` चलाइयो भने, `students` टेबलका **सबै 10 वटा row** प्रभावित हुन्छन् र सबैको `score` 0 अंक हुन्छ। `UPDATE`/`DELETE` चलाउनुअघि सधैं `WHERE` जाँच गर्नैपर्छ।

---

## प्रश्न 3 (DELETE)

### उत्तर

```sql
-- ① id=8 भएको विद्यार्थीलाई मेटाउने
DELETE FROM students WHERE id = 8;

-- ② score 40 अंकभन्दा कम भएका सबै विद्यार्थीलाई मेटाउने
DELETE FROM students WHERE score < 40;

-- ③ ② चलाउनुअघि, लक्षित row हरू SELECT ले जाँच्ने
SELECT * FROM students WHERE score < 40;
```

**नतिजा (सन्दर्भका लागि):**
- ①: 吉田健太 (id=8) मेटिन्छ
- ②: सुरुको डाटामा सबैभन्दा कम अंक 45 (加藤幸子) भएकाले, `score < 40` मा पर्ने विद्यार्थी **0 जना** छन्। अर्थात् यो `DELETE` ले केही पनि मेटाउँदैन ("लक्षित row 0" हुनु पनि सही नतिजा हो)
- ③: ② को `DELETE` चलाउनुअघि सधैं यो `SELECT` चलाउनुहोस् र मेटिने row हरू आफूले चाहेकै हुन् कि होइनन् भनेर जाँचेपछि मात्र `DELETE` चलाउनुहोस् (सामग्रीको अध्याय 4 "सुरक्षित रूपमा UPDATE/DELETE गर्ने तरिका" हेर्नुहोस्)
