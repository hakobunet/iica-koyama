# कक्षा 02 अभ्यास｜PHP को आधारभूत सिन्ट्याक्स चलाएर हेरौँ

> 🇯🇵 मूल प्रति (जापानी भाषामा): [20260630_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260630/20260630_演習.md>) <!-- original-ja-link -->

`src/index.php` बनाएर, हरेक प्रश्नको कोड लेख्नुहोस् र `php -S localhost:8000` ले चलाएर जाँच गर्नुहोस्।

---

## प्रश्न 1: आफ्नो परिचय देखाउने

`$name`・`$age`・`$hobby` भेरिएबलहरू परिभाषित गरेर, तल जस्तै देखिने PHP फाइल लेख्नुहोस्।

**अपेक्षित आउटपुटको उदाहरण (ब्राउजरमा देखिने):**
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

सर्तहरू:
- भेरिएबल सधैँ `$` बाट सुरु गर्ने
- स्ट्रिङभित्र भेरिएबल राख्ने `"..."` शैलीमा आउटपुट गर्ने

```php
<?php
// यहाँ लेख्नुहोस्


?>
```

---

## प्रश्न 2: एरेलाई HTML सूचीमा देखाउने

`$fruits = ["りんご", "みかん", "ぶどう", "バナナ"]` लाई `foreach` ले लुप गरेर, `<ul>` / `<li>` ट्याग प्रयोग गरी HTML मा देखाउनुहोस्।

**अपेक्षित आउटपुट (ब्राउजरमा देखिने):**
```
• りんご
• みかん
• ぶどう
• バナナ
```

सर्तहरू:
- `foreach` प्रयोग गर्ने
- HTML को `<ul>` र `<li>` ट्याग echo ले आउटपुट गर्ने

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// यहाँ लेख्नुहोस्


?>
```

---

## प्रश्न 3: 1 देखि 10 सम्मको योगफल निकाल्ने

`for` लुप प्रयोग गरेर 1 देखि 10 सम्मका सबै पूर्णाङ्क जोड्नुहोस् र प्राप्त योगफल आउटपुट गर्नुहोस्।

**अपेक्षित आउटपुट:**
```
合計: 55
```

सर्तहरू:
- `for` लुप प्रयोग गर्ने
- योगफल राख्न `$total` भेरिएबल प्रयोग गर्ने

```php
<?php
$total = 0;

// यहाँ लेख्नुहोस्


echo "合計: " . $total;
?>
```

---

## प्रश्न 4 (उन्नत): गुणन तालिका बनाउने

`for` लुपलाई दोहोरो (nested) प्रयोग गरेर, 2 देखि 5 सम्मको गुणन तालिका देखाउनुहोस्।

**अपेक्षित आउटपुट (केही भाग):**
```
2×1=2  2×2=4  2×3=6 ...
3×1=3  3×2=6  3×3=9 ...
```

```php
<?php
// यहाँ लेख्नुहोस्


?>
```
