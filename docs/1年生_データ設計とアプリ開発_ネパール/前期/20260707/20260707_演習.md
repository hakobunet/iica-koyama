## Part 3｜फर्म र POST

### प्रश्न 3-1: सम्पर्क (inquiry) फर्म बनाउने

`contact.php` लाई एउटै फाइलमा बनाउनुहोस्।

**स्पेसिफिकेसन:**
- इनपुट फिल्डहरू: नाम・इमेल ठेगाना・सन्देश
- पठाएपछि "〇〇さんからのお問い合わせを受け付けました" (〇〇 जीको सोधपुछ प्राप्त भयो) देखाउने
- XSS बाट बच्न `htmlspecialchars()` अनिवार्य रूपमा प्रयोग गर्ने

```php
<?php
// ▼ contact.php मा लेख्नुहोस्

$name    = "";
$email   = "";
$message = "";
$sent    = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // ① डाटा निकाल्ने (?? "" ले null बाट बच्ने)

    // ② htmlspecialchars बाट पास गराउने

    $sent = true;
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>問い合わせ</title></head>
<body>
<?php if ($sent): ?>
  <!-- पठाउने प्रक्रिया पूरा भएको सन्देश -->
<?php else: ?>
  <!-- फर्म -->
<?php endif; ?>
</body>
</html>
```
