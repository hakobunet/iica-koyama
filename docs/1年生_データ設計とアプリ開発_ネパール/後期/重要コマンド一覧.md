# महत्त्वपूर्ण कमान्डहरूको सूची

> 🇯🇵 मूल प्रति (जापानी भाषामा): [重要コマンド一覧.md](<../../1年生_データ設計とアプリ開発/後期/重要コマンド一覧.md>) <!-- original-ja-link -->

> कमान्डहरू **VS Code को टर्मिनल** मा टाइप गर्नुहोस्।
> Docker Desktop सुरु गरेपछि मात्र प्रयोग गर्नुहोस्।

---

## सुरु गर्ने र रोक्ने

### सुरु गर्ने (mysql → laravel को क्रममा)

```powershell
docker compose up -d
```

### रोक्ने (laravel → mysql को क्रममा)

```powershell
docker compose down
```

सुरु भएपछि, ब्राउजरमा खोल्नुहोस्।

| URL | हेर्न सकिने कुरा |
|-----|------------|
| http://localhost:8000 | Laravel (तपाईंले बनाइरहेको एप) |
| http://localhost:8080 | phpMyAdmin (डाटाबेस) |

---

## फाइल बनाउने

laravel फोल्डरमा टाइप गर्नुहोस्।

### माइग्रेसन फाइल बनाउने

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### मोडेल बनाउने

```powershell
docker compose exec laravel php artisan make:model Todo
```

### कन्ट्रोलर बनाउने

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## डाटाबेस चलाउने

laravel फोल्डरमा टाइप गर्नुहोस्।

### टेबल बनाउने

```powershell
docker compose exec laravel php artisan migrate
```
