> 🇯🇵 මුල් පිටපත (ජපන් භාෂාවෙන්): [課題提出ルール.md](<../../1年生_前期_ITシステム基礎/課題提出ルール/課題提出ルール.md>) <!-- original-ja-link -->

## දළ විශ්ලේෂණය
 
පහත සඳහන් නීති **සියල්ලම සපුරාලන නිර්මාණයක්** ඉදිරිපත් කරන්න.

ඔබ භාවිත කරන තාක්ෂණය (GAS, localStorage ආදී) කුමක් වුවත් කමක් නැත.  
**ඇගයීම කරන්නේ "එයට කුමක් කළ හැකිද" යන්න අනුවයි.**

## අනිවාර්ය ක්‍රියාකාරී අවශ්‍යතා

### 2. බාහිර API සමඟ සන්නිවේදනය

බාහිර API එකකට ඉල්ලීමක් යවා, ලැබුණු දත්ත තිරයේ පෙන්විය යුතුය.

- උදාහරණ: කාලගුණ API, විනිමය අනුපාත API, පුවත් API ආදිය
- API ප්‍රතිචාරය එලෙසම පෙන්වීම පමණක් නොව, **තිරයේ දර්ශනයට හෝ පද්ධතියේ ක්‍රියාකාරිත්වයට එය යොදාගත යුතුය**

- [ ] **ඔබම ලියූ function** දෙකක් හෝ වැඩි ගණනක් අර්ථ දක්වන්න
- [ ] **කොන්දේසි අනුව අතු බෙදීමක්** (`if / else`) අවම වශයෙන් එකක් ලියන්න

## ඉදිරිපත් කිරීමේදී පැහැදිලි කළ යුතු දේ

1. **එය සෑදුවේ කුමක් සඳහාද** (අරමුණ, විසඳන ගැටලුව)

## යොමුව: "සමත් මට්ටමේ" උදාහරණ

### ✅ අවම මට්ටම සපුරා ඇති උදාහරණ

- **කාර්ය කළමනාකරණ මෙවලම**: කාර්ය එකතු කිරීම, ලැයිස්තුවක් ලෙස පෙන්වීම, සම්පූර්ණ කළ බවට යාවත්කාලීන කිරීම සහ මකා දැමීම කළ හැකි අතර, අද කාලගුණය API මගින් පෙන්වයි
- **පොත් එකතුව කළමනාකරණය**: පොත් ලියාපදිංචි කිරීම, ලැයිස්තුව, සංස්කරණය, මකා දැමීම කළ හැකි අතර, ISBN අංකයෙන් පොතේ තොරතුරු API මගින් ලබාගෙන ස්වයංක්‍රීයව පුරවයි
- **සටහන් යෙදුම**: සටහන් සෑදීම, ලැයිස්තුව, සංස්කරණය, මකා දැමීම කළ හැකි අතර, කාලගුණ API භාවිතයෙන් අද මනෝභාවය සටහන් කරන කොටුවේ පෙන්වයි

### ❌ නීති සපුරා නොමැති උදාහරණ
