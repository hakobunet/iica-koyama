## Part 3｜Biểu mẫu và POST

### Bài 3-1: Tạo biểu mẫu liên hệ

Hãy tạo biểu mẫu trong một file duy nhất là `contact.php`.

**Yêu cầu:**
- Các mục nhập: tên, địa chỉ email, nội dung tin nhắn
- Sau khi gửi, hiển thị "Đã tiếp nhận liên hệ từ 〇〇"
- Luôn dùng `htmlspecialchars()` để phòng chống XSS

```php
<?php
// ▼ Viết vào contact.php

$name    = "";
$email   = "";
$message = "";
$sent    = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // ① Lấy dữ liệu ra (dùng ?? "" để phòng trường hợp null)

    // ② Xử lý dữ liệu bằng htmlspecialchars

    $sent = true;
}
?>
<!DOCTYPE html>
<html lang="ja">
<head><meta charset="UTF-8"><title>問い合わせ</title></head>
<body>
<?php if ($sent): ?>
  <!-- Thông báo gửi thành công -->
<?php else: ?>
  <!-- Biểu mẫu -->
<?php endif; ?>
</body>
</html>
```
