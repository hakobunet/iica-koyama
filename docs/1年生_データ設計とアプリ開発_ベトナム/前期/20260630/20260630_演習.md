# Tiết 02 Bài tập｜Chạy thử cú pháp cơ bản của PHP

> 🇯🇵 Bản gốc (tiếng Nhật): [20260630_演習.md](<../../../1年生_データ設計とアプリ開発/前期/20260630/20260630_演習.md>) <!-- original-ja-link -->

Hãy tạo file `src/index.php`, viết code cho từng bài rồi kiểm tra kết quả bằng `php -S localhost:8000`.

---

## Bài 1: Hiển thị phần giới thiệu bản thân

Hãy khai báo các biến `$name`・`$age`・`$hobby` và viết một file PHP hiển thị như dưới đây.

**Ví dụ kết quả mong đợi (hiển thị trên trình duyệt):**
```
名前：田中太郎
年齢：20歳
趣味：プログラミング
```

Điều kiện:
- Biến luôn phải bắt đầu bằng `$`
- Xuất ra theo dạng `"..."`, tức là nhúng biến vào trong chuỗi

```php
<?php
// Viết code ở đây


?>
```

---

## Bài 2: Hiển thị mảng dưới dạng danh sách HTML

Hãy dùng `foreach` để duyệt qua `$fruits = ["りんご", "みかん", "ぶどう", "バナナ"]` và hiển thị bằng HTML với các thẻ `<ul>` / `<li>`.

**Kết quả mong đợi (hiển thị trên trình duyệt):**
```
• りんご
• みかん
• ぶどう
• バナナ
```

Điều kiện:
- Phải dùng `foreach`
- Phải dùng echo để xuất ra các thẻ HTML `<ul>` và `<li>`

```php
<?php
$fruits = ["りんご", "みかん", "ぶどう", "バナナ"];

// Viết code ở đây


?>
```

---

## Bài 3: Tính tổng từ 1 đến 10

Hãy dùng vòng lặp `for` để cộng tất cả các số nguyên từ 1 đến 10 và xuất ra tổng.

**Kết quả mong đợi:**
```
合計: 55
```

Điều kiện:
- Phải dùng vòng lặp `for`
- Phải dùng biến `$total` để lưu tổng

```php
<?php
$total = 0;

// Viết code ở đây


echo "合計: " . $total;
?>
```

```
3×1=3  3×2=6  3×3=9 ...
```
