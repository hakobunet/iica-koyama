# Tiết 07 Bài tập｜Đáp án mẫu

Đây là đáp án mẫu dựa trên dữ liệu của bảng `students` (xem tài liệu tiết 07).

---

## Bài 1 (SELECT cơ bản)

### Đáp án

```sql
-- ① Chỉ lấy name và class
SELECT name, class FROM students;

-- ② Lấy với name AS 氏名, score AS 点数
SELECT name AS 氏名, score AS 点数 FROM students;

-- ③ Lấy tất cả các cột và tất cả các dòng
SELECT * FROM students;
```

---

## Bài 2 (WHERE)

### Đáp án

```sql
-- ① Học sinh có class là 'B'
SELECT * FROM students WHERE class = 'B';

-- ② age từ 18 tuổi trở lên và score từ 80 điểm trở lên
SELECT * FROM students WHERE age >= 18 AND score >= 80;

-- ③ class là 'A' hoặc 'C'
SELECT * FROM students WHERE class IN ('A', 'C');

-- ④ name có chứa "郎"
SELECT * FROM students WHERE name LIKE '%郎%';
```

**Kết quả (tham khảo):**
- ①: 山田次郎(91), 佐藤三郎(58), 吉田健太(88)
- ②: 田中太郎(85), 山田次郎(91), 渡辺一郎(95), 吉田健太(88)
- ③: 田中太郎・鈴木花子・伊藤美咲・山本麻衣 (A), 渡辺一郎・加藤幸子・中村龍一 (C)
- ④: 田中太郎・山田次郎・佐藤三郎・渡辺一郎 (4 học sinh)

## Bài 3 (ORDER BY / LIMIT)

### Đáp án

```sql
-- ① Toàn bộ học sinh theo score giảm dần
SELECT * FROM students ORDER BY score DESC;

-- ② Chỉ 3 học sinh đứng đầu
SELECT * FROM students ORDER BY score DESC LIMIT 3;

-- ③ class tăng dần, trong cùng class thì score giảm dần
SELECT * FROM students ORDER BY class ASC, score DESC;
```

**Kết quả (tham khảo):**

②
```
渡辺一郎 95点
山田次郎 91点
吉田健太 88点
```

③

```
[C] 渡辺一郎95, 中村龍一73, 加藤幸子45
```

## Bài 4 (hàm tổng hợp)

### Đáp án

```sql
-- ① Số học sinh
SELECT COUNT(*) FROM students;

-- ② Lấy cùng lúc tổng, trung bình, cao nhất, thấp nhất
SELECT
    SUM(score) AS 合計点,
    AVG(score) AS 平均点,
    MAX(score) AS 最高点,
    MIN(score) AS 最低点
FROM students;
```

**Kết quả (tham khảo):**
- ①: 10 học sinh
- ②: Tổng điểm 752 / Điểm trung bình 75.2 / Điểm cao nhất 95 / Điểm thấp nhất 45

---

## Bài 5 (nâng cao)

### Đáp án

```sql
-- ① Với các học sinh từ 60 điểm trở lên, tính điểm trung bình và số học sinh theo từng class, rồi sắp xếp theo điểm trung bình từ cao đến thấp
SELECT class, AVG(score) AS 平均点, COUNT(*) AS 人数
FROM students
WHERE score >= 60
GROUP BY class
ORDER BY 平均点 DESC;

-- ② Chỉ 1 học sinh có điểm cao nhất trong class = 'A'
SELECT * FROM students
WHERE class = 'A'
ORDER BY score DESC
LIMIT 1;
```

**Kết quả (tham khảo):**

① (佐藤三郎 và 加藤幸子 dưới 60 điểm nên bị loại)
```
B: 平均点 89.5, 人数 2
C: 平均点 84.0, 人数 2
A: 平均点 75.5, 人数 4
```

②
```
田中太郎 85点
```
