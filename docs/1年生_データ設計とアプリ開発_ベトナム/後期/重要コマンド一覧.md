> Các lệnh được gõ trong **terminal của VS Code**.
> Hãy khởi động Docker Desktop trước khi dùng nhé.

---

## Khởi động và dừng

### Khởi động (theo thứ tự mysql → laravel)

```powershell
docker compose up -d
```

### Dừng (theo thứ tự laravel → mysql)

```powershell
docker compose down
```

Sau khi khởi động, hãy mở các địa chỉ sau trong trình duyệt.

| URL | Những gì xem được |
|-----|------------|
| http://localhost:8000 | Laravel (ứng dụng đang phát triển) |
| http://localhost:8080 | phpMyAdmin (cơ sở dữ liệu) |

---

## Tạo file

Gõ lệnh trong thư mục laravel.

### Tạo file migration

```powershell
docker compose exec laravel php artisan make:migration create_todos_table
```

### Tạo model

```powershell
docker compose exec laravel php artisan make:model Todo
```

### Tạo controller

```powershell
docker compose exec laravel php artisan make:controller TodoController
```

---

## Thao tác với cơ sở dữ liệu

Gõ lệnh trong thư mục laravel.

### Tạo bảng

```powershell
docker compose exec laravel php artisan migrate
```
