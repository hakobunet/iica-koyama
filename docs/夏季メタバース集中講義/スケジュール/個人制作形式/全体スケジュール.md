# Roblox メタバース講習 全体スケジュール（個人制作形式・4日間）

参加人数が少ない場合（目安：〜9人程度、3チーム未満）に選ぶ形式。`ハッカソン形式`との違いは、**企画書コンテスト・審査・表彰式を行わないこと**、そして**1〜2日目を丸ごと学習講義に充て、3〜4日目を自由制作＋発表会にすること**。各日の詳細進行は`◯日目.md`を参照。

## ハッカソン形式との違い

| | ハッカソン形式 | 個人制作形式（このページ） |
|---|---|---|
| 想定人数 | 10人前後〜（3チーム以上組める規模） | 〜9人程度 |
| 2日目午後 | 企画会議・役割分担 | 応用パターン講義の続き（`04`を全部講義） |
| 3〜4日目 | 企画実装（開発フェーズ）→発表→審査・表彰式 | 自由制作→発表会（審査なし） |
| 企画書 | あり（企画書コンテスト） | なし |
| 審査・表彰式 | あり | なし |
| 実装時間（正味） | 約5時間45分（タイト） | 約8時間前後（余裕あり。作り込みを推奨） |

## 実装時間の考え方

正味の制作時間は3・4日目合わせて約8時間前後（`ハッカソン形式`の約5時間45分より余裕がある）。この余裕は「時間を持て余す」ためのものではなく、「作り込みたいだけ作り込める」ためのものと位置づける。最低ライン（`04`の1パターンをそのまま形にする）は確実に間に合うため、余裕がありそうな個人・チームには`04`のパターンを2つ組み合わせる、`04`の5章（Tool・Teams・タイマー・ClickDetector）に挑戦する、`05`のより難しいアイデアに挑戦する、といった上乗せを提案する。
