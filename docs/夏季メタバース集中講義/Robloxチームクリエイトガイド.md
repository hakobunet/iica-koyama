# Robloxチームクリエイト（Team Create）ガイド

想定用途：チームメンバー全員が同じ空間（Place）に同時接続し、リアルタイムで一緒に編集できる状態にするための手順を1か所にまとめた資料。2日目2限の後半（学習講義②が終わった直後、11:45〜）で実際に使う。

## この資料の位置づけ

Team Createに関する説明は`Roblox講義/01_Studio基本操作リファレンス.md`（9章）や`スケジュール/2日目.md`（2限）など複数の資料に分散している。本資料はその内容を1つにまとめ、当日「Team Createってどうやるんだっけ」となったときにすぐ参照できるようにしたもの。

## 1. Team Createとは

複数人が同じPlace（仮想空間）に同時に入り、リアルタイムで一緒に編集できるRoblox Studioの機能。誰か1人がパーツを動かすと、他のメンバーの画面にもすぐ反映される。実際のゲーム開発チームが行う共同編集プロセスをそのまま体験できることから、このハッカソンの技術的な核として選ばれている（詳しくは[`オリエンテーション/メタバースとは.md`](./オリエンテーション/メタバースとは.md)参照）。

## 2. 事前に必要な条件

Team Createを使うには、接続手順に入る前に以下の2つを満たしている必要がある。どちらも欠けると、招待してもEdit権限が付かない・接続できないといった形でつまずくので注意。

- **年齢確認（Age Check）を全員が完了していること**：Robloxは2026年以降、Team Createとゲーム内チャットの両方で年齢確認（顔認証 or 身分証確認）を必須にしている。未実施のアカウントはTeam Createに参加できない（[`Robloxセットアップガイド.md`](./Robloxセットアップガイド.md)で事前に済ませておく。顔認証を先に試し、通らなかった場合のみ身分証確認に切り替える）
- **チームメンバー同士がRoblox上で「友達」になっていること**：個人所有のPlaceでは、Edit権限を付与できる相手は原則Roblox上の友達に限られる（グループ所有のPlaceの場合は不要）。この講義ではPlaceを個人所有で作るため、友達申請・承認が必要
  - 年齢確認後のグループ分けは「Under 9／9-12／13-15／16-17／18+」の5区分で、**18歳以上は全員まとめて同じ「18+」グループ**になる。参加者は全員18歳以上のため、年齢帯をまたぐ追加の制約（Trusted Friends認定・保護者権限）は発生しない

## 3. 接続手順

1. チームで「Place作成担当（リーダー）」を1名決める（じゃんけん等でよい）
2. **チーム全員がRoblox上で友達申請・承認を済ませる**（まだの場合はここで行う）
   - 画面上部の「Friends」メニュー内の検索欄では**既存の友達しか出てこない**ので使わない
   - 代わりに画面最上部のサイト全体の検索バーにユーザー名を入力し、「People（ユーザー）」カテゴリで絞り込む
   - 該当ユーザーのプロフィールページを開き、「Add Friend」ボタンを押す→相手が承認して完了
3. リーダーがRobloxの「Create」ページ（[https://create.roblox.com](https://create.roblox.com)）で新規Placeを作成し、チーム名を付ける
4. リーダーが、作成したPlaceの設定画面から「Collaborators（コラボレーター）」の項目を開き、他のメンバーをRobloxのユーザー名で検索して招待する。権限は「編集可能（Can Edit）」にする
5. メンバー側は、Robloxからの招待通知を承認する
6. 全員がStudioからそのPlaceを開くと、画面右上に参加中のメンバーのアイコンが並んで表示される。これがTeam Create接続の成功サイン
7. 誰か1人がパーツを動かすと、他のメンバーの画面にもリアルタイムで反映される

## 4. 接続確認のやり方（挨拶ブロック）

2日目2限（学習講義②が終わった直後）では、単なる接続確認で終わらせず「他人の操作がリアルタイムに見える」共同編集ならではの体験を最初に持たせるため、以下を行う。

1. チーム全員が同じ共有Placeを開き、Team Createに同時接続していることを確認する
2. 各メンバーが自分の色のパーツを1つ配置し、そこに自分の名前をタグ付け（Partを配置→Propertiesの`Name`に名前を入力）して「挨拶ブロック」とする
3. 全員のブロックが同じ空間内に並んでいることを確認できたら完了

## 5. よくあるトラブルと対処

| 症状 | 対処 |
|---|---|
| Collaboratorに招待したのにEdit権限が付かない（相手のドロップダウンが「Play」のまま変更できない） | リーダーとそのメンバーがRoblox上で友達になっていない可能性が高い。先に友達申請・承認を済ませてから招待し直す |
| 友達申請したい相手が「Friends」メニューの検索に出てこない | その検索欄は既存の友達しか表示されない仕様。画面最上部のサイト全体の検索バーで「People」カテゴリを使って検索する |
| Team Createに接続できない・参加できない | 年齢確認（Age Check）が未完了の可能性が高い。当日その場での顔認証は数分で終わるので、気づいたら速やかに個別対応する |
| Team Createで他メンバーが見えない | Place作成者の権限設定（Collaborators）を再確認する。招待メールやRoblox内通知の見落としが多い |
| Wi-Fiが不安定でPlaceが同期しない | 座席とアクセスポイントの位置関係を事前確認しておく。詰まったチームは講師PCのホットスポット等を予備手段として用意しておくと安心 |
| 同時編集でPCが重くなる | 不要なパーツを都度Deleteして整理する。Team Createは同時接続人数が多いほど負荷が上がりやすい |
| Studioが起動しない／重い | 学校PCのスペック差が原因の場合が多い。[`Robloxセットアップガイド.md`](./Robloxセットアップガイド.md)の該当章を参照し、描画設定を下げる |
