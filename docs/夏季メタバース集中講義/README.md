# 夏メタバース講習｜資料の読み方

開催形式は[`スケジュール/`](./スケジュール/全体スケジュール.md)（チーム対抗のハッカソン。企画書コンテスト・審査・表彰式あり。2日目午後から企画会議＋実装）。

Robloxの技術的な教材は共通で、[`Roblox講義/`](./Roblox講義/)フォルダ（01〜05）と[`Robloxリリース・公開ガイド.md`](./Robloxリリース・公開ガイド.md)を参照する。

## 教えていく順番

技術教材は番号順に積み上がる構成になっている。**口頭講義で扱うのは`03`まで**で、`04`・`05`は「講師の説明がなくても読めば実装できる」ことを前提にした自己参照用の資料。

| # | 資料 | タイミング | 扱い方 |
|---|---|---|---|
| 1 | [`01_Studio基本操作リファレンス.md`](./Roblox講義/01_Studio基本操作リファレンス.md) | 1日目2〜4限 | 口頭講義 |
| 2 | [`02_Lua基礎文法リファレンス.md`](./Roblox講義/02_Lua基礎文法リファレンス.md) | 1日目4限〜2日目1限 | 口頭講義 |
| 3 | [`03_コードスニペット集.md`](./Roblox講義/03_コードスニペット集.md) | 2日目1〜2限 | 口頭講義（ここまでで、コイン集めゲームが完成する） |
| 4 | [`04_応用アレンジパターン集.md`](./Roblox講義/04_応用アレンジパターン集.md) | 2日目3限以降 | 自己参照。チームが企画に応じて必要な章だけ読む |
| 5 | [`05_アイデア集.md`](./Roblox講義/05_アイデア集.md) | 2日目3限以降〜企画決め | 自己参照。`01`〜`03`の範囲だけで作れる企画例集。`04`より先に、企画に迷ったときの入り口として読んでもよい |
| 6 | [`Robloxリリース・公開ガイド.md`](./Robloxリリース・公開ガイド.md) | 4日目、発表前 | 自己参照。作った作品をPublishして公開する手順 |

`01`〜`03`だけでも、収集・サバイバル・タイムアタック・非コーディングの共同制作など一定の幅で企画が作れる（詳細は`05`を参照）。`04`はショップ化（通貨）・脱出ゲーム化（鍵）など新しいAPIを使いたいチームのための発展資料という位置づけ。
