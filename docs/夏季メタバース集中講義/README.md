# 夏メタバース講習｜資料の読み方

参加人数によって、2つの開催形式のどちらかを選ぶ。
参加人数によって柔軟に対応する。

| フォルダ | 形式 | 想定人数 | 特徴 |
|---|---|---|---|
| `ハッカソン形式/` | チーム対抗のハッカソン | 10人前後〜（3チーム以上） | 企画書コンテスト・審査・表彰式あり。2日目午後から企画会議＋実装 |
| `個人制作形式/` | 少人数向けの学習＋自由制作 | 〜9人程度 | 企画書・審査・表彰式なし。1〜2日目は終日講義、3〜4日目は自由制作＋発表会のみ |

どちらの形式でも、Robloxの技術的な教材（Studio操作・Lua文法・コイン集めゲーム・応用パターン・アイデア集）は共通で、`Roblox講義/`フォルダ（01〜06）を参照する。

## 共通資料
- `Roblox講義/` … 01〜06の技術リファレンス（Studio操作・Lua基礎・コイン集めゲーム・応用アレンジ・アイデア集・リリース手順）。形式によらず共通
- `メタバースとは.md` / `スライド/` … メタバース概論の資料
- `Robloxセットアップガイド.md` … 事前準備用のセットアップ手順

## 形式ごとの資料
- `ハッカソン形式/全体スケジュール.md` … チーム対抗ハッカソン版の4日間スケジュール
- `個人制作形式/全体スケジュール.md` … 少人数向け学習＋自由制作版の4日間スケジュール（ハッカソン形式との違いの比較表あり）

人数が確定してから、どちらの形式で進めるかを選び、該当フォルダの`全体スケジュール.md`から読み進める。
