# 夏メタバース講習｜資料の読み方

参加人数によって、2つの開催形式のどちらかを選ぶ。

| フォルダ | 形式 | 想定人数 | 特徴 |
|---|---|---|---|
| [`ハッカソン形式/`](./スケジュール/ハッカソン形式/全体スケジュール.md) | チーム対抗のハッカソン | 10人前後〜（3チーム以上） | 企画書コンテスト・審査・表彰式あり。2日目午後から企画会議＋実装 |
| [`個人制作形式/`](./スケジュール/個人制作形式/全体スケジュール.md) | 少人数向けの学習＋自由制作 | 〜9人程度 | 企画書・審査・表彰式なし。1〜2日目は終日講義、3〜4日目は自由制作＋発表会のみ |

どちらの形式でも、Robloxの技術的な教材は共通で、[`Roblox講義/`](./Roblox講義/)フォルダ（01〜05）と[`Robloxリリース・公開ガイド.md`](./Robloxリリース・公開ガイド.md)を参照する。

## 教えていく順番

技術教材は番号順に積み上がる構成になっている。**口頭講義で扱うのは`03`まで**で、`04`・`05`は「講師の説明がなくても読めば実装できる」ことを前提にした自己参照用の資料。

| # | 資料 | タイミング | 扱い方 |
|---|---|---|---|
| 1 | [`01_Studio基本操作リファレンス.md`](./Roblox講義/01_Studio基本操作リファレンス.md) | 1日目2〜4限 | 口頭講義 |
| 2 | [`02_Lua基礎文法リファレンス.md`](./Roblox講義/02_Lua基礎文法リファレンス.md) | 1日目4限〜2日目1限 | 口頭講義 |
| 3 | [`03_コードスニペット集.md`](./Roblox講義/03_コードスニペット集.md) | 2日目1〜2限 | 口頭講義（ここまでで、コイン集めゲームが完成する） |
| 4 | [`04_応用アレンジパターン集.md`](./Roblox講義/04_応用アレンジパターン集.md) | 2日目3限以降 | 自己参照（`個人制作形式`は2日目3〜4限に口頭講義もあり）。チームが企画に応じて必要な章だけ読む |
| 5 | [`05_アイデア集.md`](./Roblox講義/05_アイデア集.md) | 2日目3限以降〜企画決め | 自己参照。`01`〜`03`の範囲だけで作れる企画例集。`04`より先に、企画に迷ったときの入り口として読んでもよい |
| 6 | [`Robloxリリース・公開ガイド.md`](./Robloxリリース・公開ガイド.md) | 4日目、発表前 | 自己参照。作った作品をPublishして公開する手順 |

`01`〜`03`だけでも、収集・サバイバル・タイムアタック・非コーディングの共同制作など一定の幅で企画が作れる（詳細は`05`を参照）。`04`はショップ化（通貨）・脱出ゲーム化（鍵）など新しいAPIを使いたいチームのための発展資料という位置づけ。

## 共通資料
- [`Roblox講義/`](./Roblox講義/) … 01〜05の技術リファレンス（Studio操作・Lua基礎・コイン集めゲーム・応用アレンジ・アイデア集）。形式によらず共通
- [`Robloxリリース・公開ガイド.md`](./Robloxリリース・公開ガイド.md) … 完成した作品をRoblox上に公開する手順。形式によらず共通
- [`メタバースについて講義/メタバースとは.md`](./メタバースについて講義/メタバースとは.md) / [`スライド/`](./メタバースについて講義/スライド/) … メタバース概論の資料
- [`Robloxセットアップガイド.md`](./Robloxセットアップガイド.md) … 事前準備用のセットアップ手順

## 形式ごとの資料
- [`ハッカソン形式/全体スケジュール.md`](./スケジュール/ハッカソン形式/全体スケジュール.md) … チーム対抗ハッカソン版の4日間スケジュール
- [`個人制作形式/全体スケジュール.md`](./スケジュール/個人制作形式/全体スケジュール.md) … 少人数向け学習＋自由制作版の4日間スケジュール（ハッカソン形式との違いの比較表あり）

人数が確定してから、どちらの形式で進めるかを選び、該当フォルダの`全体スケジュール.md`から読み進める。
