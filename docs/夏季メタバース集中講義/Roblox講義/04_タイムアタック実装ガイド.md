## クリアタイム計測（スタート→ゴールの経過時間を記録する）

ゴールまでに実際にかかった時間そのものを計測して表示する仕組み。タイムアタック企画の核となる要素。

### 作りたいものの流れ
1. スタート地点のパーツに触れると、その瞬間の時刻を記録する
2. ゴール地点のパーツに触れると、記録しておいた時刻との差を計算し、「クリアタイム」として画面に表示する

### 手順

`ReplicatedStorage`は、サーバー側の`Script`とクライアント側の`LocalScript`の両方から中身を見られる特別な置き場所。ここでは、サーバー側で計算したクリアタイムの値を、クライアント側のGUI（画面表示）からも読み取れるようにするために使う。`NumberValue`は小数を含む数値（`1.5`のような値）を保存できる箱で、整数だけでよい場合は次のセクションのように`IntValue`を使う。

1. Explorerで`ReplicatedStorage`を右クリック→「Insert Object」→`NumberValue`を挿入し、`Name`を`ElapsedTime`に変更する
2. `workspace`にスタート地点のパーツを配置し`Name`を`StartLine`に、ゴール地点のパーツを配置し`Name`を`Finish`に変更する
3. `ServerScriptService`に新しい`Script`を挿入し、以下を入力する

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local elapsedTime = ReplicatedStorage:WaitForChild("ElapsedTime")

local startLine = workspace:WaitForChild("StartLine")
local finishLine = workspace:WaitForChild("Finish")

local startTime = nil

startLine.Touched:Connect(function(hit)
	if startTime ~= nil then
		return
	end

	startTime = os.clock()
	elapsedTime.Value = 0
	print(elapsedTime.Value)
end)

finishLine.Touched:Connect(function(hit)
	if startTime == nil then
		return
	end

	elapsedTime.Value = os.clock() - startTime
	startTime = nil
end)

-- 走行中は経過時間をリアルタイムに更新する
-- これによりクリアタイムのラベルが常に更新される
while true do
	task.wait(0.1)
	if startTime ~= nil then
		elapsedTime.Value = os.clock() - startTime
	end
end

```

4. `03_コードスニペット集.md`の`E`（GUIでスコアを表示する）と同じ要領で、`StarterGui`に`ScreenGui`→`TextLabel`→`LocalScript`を用意し、以下を入力する

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local elapsedTime = ReplicatedStorage:WaitForChild("ElapsedTime")
local label = script.Parent

local function updateLabel()
    label.Text = "クリアタイム: " .. string.format("%.1f", elapsedTime.Value) .. "秒"
end

elapsedTime:GetPropertyChangedSignal("Value"):Connect(updateLabel)
updateLabel()
```

5. Playモードに入り、`StartLine`に触れてから`Finish`に触れると、画面に「クリアタイム: ◯◯秒」と表示されることを確認する

- **コードの意味**：`os.clock()`は「プログラムが起動してからの経過時間」を秒単位の数値で返す関数（似た働きの`tick()`という関数もあるが、そちらは非推奨のため使わない）。`StartLine`に触れた瞬間の時刻を`startTime`という変数に覚えておき、`Finish`に触れた瞬間の時刻との差（`os.clock() - startTime`）を計算することで、「スタートからゴールまで何秒かかったか」が求まる。`startTime`は最初`nil`（何も入っていない状態）にしておき、`if startTime ~= nil then return end`で「すでに計測中なら`StartLine`への再接触は無視する」、`if startTime == nil then return end`で「まだスタートしていないのに`Finish`に触れても何もしない」というガードをそれぞれ入れている。`StartLine`に触れた瞬間に`elapsedTime.Value`を`0`に戻しているので、GUI側にも「計測が始まった」ことが伝わり、前回のタイムが表示されたままになることもない
- **どこで使うか**：タイムアタックコースのクリアタイム表示、ランキング企画のスコア（タイム）算出の基礎
- **よくあるエラー**：`StartLine`と`Finish`の`Name`のスペルミス。また、この実装は`startTime`・`ElapsedTime`を1つの値で管理しているため、複数人が同時に走ると計測がお互いに干渉してしまう（誰かが計測中に別の人が`StartLine`に触れても、ガードによって無視される。1人が走り終わってからでないと次の人は計測を開始できない）。1人ずつ順番に走らせる運用が前提になっている点に注意
- **発展**：次の「制限時間・カウントダウンタイマー」と組み合わせると、「制限時間内にゴールできたら、そのときのタイムを記録する」という本格的なタイムアタックに発展させられる（`TimeLeft`が0になる前に`Finish`に触れたかどうかで成功・失敗を判定し、成功時のみ`ElapsedTime`をクリアタイムとして採用する）。また、複数人が同時にプレイできるようにしたい場合は、この`ElapsedTime`を1つのグローバルな値ではなく、`03_コードスニペット集.md`のC・Dの`leaderstats`と同じ考え方でプレイヤーごとの値として持たせると、各自の記録を個別に管理できる。走っている間の経過時間をリアルタイムで表示し続けたい場合は、次のセクションのような`while true do ... task.wait() ... end`のループでカウントアップし続ける処理を組み合わせる

## 制限時間・カウントダウンタイマー

ゲーム全体に制限時間を設け、時間内にクリアできたかどうかで結果を変える仕組み。上のクリアタイム計測と組み合わせると、サバイバル・タイムアタック系の企画がより本格的になる。

### 作りたいものの流れ
1. ゲーム開始と同時にカウントダウンが始まる
2. 画面に残り時間が表示される
3. 時間切れになったら、何らかの処理（ゲーム終了など）を行う

### 手順

1. Explorerで`ReplicatedStorage`を右クリック→「Insert Object」→`IntValue`を挿入し、`Name`を`TimeLeft`に変更する
2. `ServerScriptService`に新しい`Script`を挿入し、以下を入力する

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local timeLeft = ReplicatedStorage:WaitForChild("TimeLeft")

timeLeft.Value = 60

while timeLeft.Value > 0 do
    task.wait(1)
    timeLeft.Value -= 1
end

print("時間切れ")
```

3. `03_コードスニペット集.md`の`E`（GUIでスコアを表示する）と同じ要領で、`StarterGui`に`ScreenGui`→`TextLabel`→`LocalScript`を用意し、以下を入力する

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local timeLeft = ReplicatedStorage:WaitForChild("TimeLeft")
local label = script.Parent

local function updateLabel()
    label.Text = "残り時間: " .. timeLeft.Value
end

timeLeft:GetPropertyChangedSignal("Value"):Connect(updateLabel)
updateLabel()
```

4. Playモードに入り、画面に「残り時間: 60」から1秒ごとにカウントダウンしていく表示が出ることを確認する

- **コードの意味**：`IntValue`を`ReplicatedStorage`（サーバーとクライアントの両方から見える場所）に置くことで、サーバー側で管理している残り時間の値を、クライアント側のGUIからも参照できるようにしている。`GetPropertyChangedSignal("Value")`で値が変わるたびに表示を更新する仕組みは、上のクリアタイム表示とまったく同じ考え方
- **どこで使うか**：生き残りゲーム・タイムアタック系企画の制限時間表示、イベントの開始・終了タイミングの管理など
- **よくあるエラー**：`ReplicatedStorage`に置いた`IntValue`の名前（`"TimeLeft"`）のスペルミス。`WaitForChild`を使わず`FindFirstChild`で直接参照すると、サーバー側の`Script`がまだ`Value`を作り終える前にクライアント側が読みにいってしまい、タイミングによってエラーになることがある
- **発展**：時間切れの瞬間に全員へ通知を送りたい場合は、`03_コードスニペット集.md`の`F`・`G`と同じ`RemoteEvent`の書き方で`FireAllClients()`を呼び出せばよい
