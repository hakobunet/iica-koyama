## 5段階評価の目安

| 点数 | 目安 |
|---|---|
| 1 | 未着手・ほぼ機能していない |
| 2 | 一部動くが不十分・粗い |
| 3 | 標準的。一通り遊べる・平凡な出来 |
| 4 | 工夫が見られ、しっかり作り込まれている |
| 5 | チームの技量・時間を踏まえて非常に優れている |

## 各項目の見るポイント

### 企画・アイデア力
- ゲームのコンセプト・遊び方に工夫や面白さがあるか
- チームとして狙いを持って作られているか

### 技術的工夫・最適化
- Studio・Luaの機能をどこまで使いこなしているか
- 「広く浅く」より「狭く深く」作り込まれているか（1つの機能を丁寧に仕上げているか）

### 完成度・デバッグ
- 実際にプレイして最後まで遊べるか、致命的なバグがないか
- 見た目（ビルド・GUIなど）の仕上がり

### プレゼンテーション
- 発表時間内に、作ったものの魅力が伝わる説明ができているか
- うまくいかなかった点を隠さず、課題にどう向き合ったかを伝えられているか
