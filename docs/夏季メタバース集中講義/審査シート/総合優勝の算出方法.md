# 総合優勝（本体表彰）の算出方法

賞は全部で2つ。
- **企画書コンテスト賞**：`企画書部門評価表.md`単体の得点で審査する、企画書そのものを評価する賞
- **本体表彰（＝総合優勝）**：`Roblox部門評価表.md`と`企画書部門評価表.md`の得点を合算した、両方の頑張りを称える賞

「本体優勝」という単体の賞は存在せず、本体表彰の枠で発表するのはこの合算スコアによる総合優勝である。

## 計算式

```
総合得点 = Roblox部門得点（／100） × 0.6 ＋ 企画書部門得点（／100） × 0.4
```

例：Roblox部門80点、企画書部門70点のチーム → 80×0.6 + 70×0.4 = 48 + 28 = **76点**

## 重み（Roblox 60 : 企画書 40）の理由

- チームの役割分担上、企画書担当は基本1人、残り2人はビルド・実装に時間を使う構造（`スケジュール/2日目.md`）のため、実際の作業時間配分に近い比率にした
- ただし0:100や70:30ほど極端にはせず、「言語化して伝える力」（企画書部門）も総合優勝に反映されるようにし、企画書コンテストの意義を薄めすぎないようにしている

## 表彰との関係

- 表彰式は`スケジュール/4日目.md`の順番どおり、①企画書コンテスト表彰（14:55-15:15）→②本体表彰＝総合優勝（15:15-15:35）の順で発表する
- ②の本体表彰では、まず企画書部門の得点を発表してから、Roblox部門の得点を発表し、最後に合算した総合優勝チームを発表する
- 1チームが両方の賞を受賞することもあり得る（例：企画書コンテスト賞と総合優勝を同じチームが受賞）
