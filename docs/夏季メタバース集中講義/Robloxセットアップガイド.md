# Robloxセットアップガイド｜事前配布資料

対象：専門学校生（IT・ゲーム・クリエイティブ専攻）
想定用途：1日目より前に、参加者が自宅のPCで完了させておく事前準備。ここに書かれた手順を1日目までに終わらせておくことで、1日目2限（環境構築）を「最終確認」だけで済ませられる状態にする。

## この資料の位置づけ

1日目2限は「チーム全員が同じ空間に同時接続できる状態」を作る回だが、その前提として各自が「Robloxアカウントを持っていて、Roblox Studioが起動する」状態になっている必要がある。当日に人数分のインストール・アカウント作成を一斉に行うと、通信環境やPC個体差によるトラブルで時間を大きく消費するため、この資料で事前に済ませてもらう。

**参加者への案内文（配布時にそのまま使える一文）**：
> 「以下の手順に沿って、①Robloxアカウントの作成、②Roblox Studioのインストール、③Studioの起動確認、の3つを1日目当日までに完了させてきてください。当日は最終確認のみ行います。」

## 事前準備チェックリスト

- [ ] Robloxアカウントを作成した
- [ ] Roblox Studioをインストールした
- [ ] Roblox Studioが起動し、ログインできることを確認した
- [ ] ノートPC本体・ACアダプタを持参できる状態にした

## 1. 動作環境の確認

| 項目 | 目安 |
|---|---|
| OS | Windows 10以降、または macOS |
| 空き容量 | 数GB以上の空き容量を推奨 |
| インターネット接続 | アカウント作成・インストール・当日のTeam Create利用に必須 |
| グラフィック性能 | 一般的なノートPCであれば動作するが、古い機種は描画設定を下げる必要がある場合がある |

- 学校指定のPCではなく自備PC（BYOD）のため、事前に上記を満たしているか各自確認しておく
- グラフィック性能はスペック表で判断する必要はない。**インストール後に実際にBaseplateを開いてみて、視点を動かしたときにカクつくかどうか**で判断すればよい。カクつく場合は下記「4. 起動確認」の後、必要に応じて描画設定を下げる（手順は5章参照）

## 2. Robloxアカウントの作成

1. ブラウザで [https://www.roblox.com](https://www.roblox.com) にアクセスする
2. トップページの「Sign Up（新規登録）」から、生年月日・ユーザー名・パスワードを入力する
   - ユーザー名は後から変更できるが、チームで見分けやすい名前にしておくと当日スムーズ
3. 登録後、案内に従ってメールアドレスを登録・認証する（機能制限を避けるため、メール認証は済ませておく）
4. ログインできる状態になっていることを確認する

📷 写真挿入：Roblox公式サイトの新規登録画面

## 3. Roblox Studioのインストール

1. Robloxアカウントでログインした状態で、[https://create.roblox.com](https://create.roblox.com) にアクセスする
2. 「Start Creating」または「Create」ボタンからRoblox Studioのダウンロードを開始する
   - 初回はインストーラー（Windowsは`.exe`、Macは`.dmg`）のダウンロードが始まる
3. ダウンロードしたインストーラーを実行し、画面の案内に従ってインストールを完了する
4. インストール完了後、Roblox Studioを起動する

📷 写真挿入：create.roblox.comのダウンロードボタン周辺画面

## 4. 起動確認

1. Roblox Studioを起動し、Robloxアカウントでログインする（ブラウザでログイン済みの場合は自動でログインされることもある）
2. 「Baseplate」などのテンプレートから新規Placeを作成できることを確認する
3. 3D空間が表示され、マウス操作（右ドラッグで視点回転、ホイールでズーム）ができることを確認する

これで1日目2限の準備は完了。画面の見方や実際の操作方法は、当日 `Roblox講義/01_Studio基本操作リファレンス.md` で扱う。

## 5. よくあるトラブルと対処

| 症状 | 対処 |
|---|---|
| インストーラーがダウンロードできない | ブラウザのポップアップブロックやセキュリティソフトの警告を確認する。学校・自宅のネットワーク制限でダウンロードがブロックされる場合は、別のネットワーク（モバイル回線等）を試す |
| Studioが起動しない／すぐ落ちる | OSが動作環境の目安を満たしているか確認する。一度アンインストールし、最新版インストーラーで入れ直す |
| 動作がカクつく／重い | → 6章の手順を、上から順に試す |
| ログインできない | メールアドレス認証が済んでいるか確認する。パスワードを忘れた場合はRoblox公式のパスワードリセット手順を利用する |
| インストールに時間がかかる／進まない | インターネット接続を確認する。自宅のWi-Fiが不安定な場合は、時間帯を変えて再試行する |

## 6. 動作がカクつく・重いときの対処

効果が大きい順に並んでいる。**上から順に試し、改善したらそこで止めてよい。**

### ステップ1：Studioの描画品質を下げる（最優先）

1. Studio起動中に画面右上の歯車アイコン（Settings）、または上部メニュー「File」→「Studio Settings」を開く
2. 左側メニューから「Rendering」を選ぶ
3. 「Quality Level」の「Automatic Quality Level」のチェックを外す
4. 表示されたスライダーを下げる（数値が小さいほど軽くなる。目安は半分以下）
5. Studioを再起動して確認する

### ステップ2：照明（Lighting）の設定を軽くする

`Future`という照明方式は、影や反射をリアルタイム計算するため負荷が高い。ステップ1でも重い場合、次にこれを試す。

1. 画面左のExplorerから`Lighting`を選ぶ
2. 画面右のPropertiesで`Technology`の項目を確認する
3. `Future`になっていたら、`Voxel`または`Compatibility`に変更する

### ステップ3：PC本体の設定を見直す（ステップ1・2でも重い場合）

- **電源に接続する**：バッテリー駆動時は自動で性能を抑える省電力モードになっている場合が多い。ACアダプタを接続し、電源プランを「高パフォーマンス」にする
- **不要なアプリを閉じる**：ブラウザの多数のタブ、Zoom/Discordなどの常駐アプリ、バックグラウンドのウイルススキャンを終了してからStudioを起動する
- **グラフィックドライバを最新にする**：数年使っているPCはドライバ更新だけで改善することがある
- **使用前に一度再起動する**：起動しっぱなしのPCはメモリが圧迫されていることが多い
- **Windowsの視覚効果を減らす**（Windowsのみ）：コントロールパネル→システム→パフォーマンス設定→「パフォーマンスを優先する」に切り替える

### 参考：それでも解決しない場合の追加設定

- **Graphics Mode（描画方式）の切り替え**：Rendering設定内の「GraphicsMode」を「Automatic」から「Direct3D 11」などに手動で変更すると改善する場合がある。主に「動かない・クラッシュする」ケースの対策で、速度改善の効果はステップ1・2より小さい
- **不要なプラグインを無効化する**：「Plugins」→「Manage Plugins」から使っていないプラグインをオフにする
- **スクリプトエディタの補完を軽くする**：2日目以降、コードを書いていて重く感じたら、Studio Settingsの「Script Editor」内の自動補完・診断機能をオフにする

## 7. 困ったときは

- 上記で解決しない場合は、1日目2限開始前の時間、または受付時に主催者へ申告する
- 当日は最終確認の時間（1日目2限冒頭10分）を設けているが、それ以前にできる限り解決しておくと、2限をスムーズに使える
